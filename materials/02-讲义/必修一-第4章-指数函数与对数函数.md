## 二、知识梳理

### 4.1 指数

**n 次方根**：若 `xⁿ = a`，则 x 叫 a 的 n 次方根。

- n 为奇数：a 的 n 次方根唯一，记作 `ⁿ√a`（a 可为负数）。
- n 为偶数：`a > 0` 时有两个互为相反数的方根 `±ⁿ√a`；`a = 0` 时为 0；`a < 0` 时在实数范围内无方根。

**根式性质**：

- `(ⁿ√a)ⁿ = a`
- n 为奇数时 `ⁿ√(aⁿ) = a`；n 为偶数时 `ⁿ√(aⁿ) = |a|`

**分数指数幂**（规定 `a > 0`，m、n 为正整数，n > 1）：

```
a^(m/n) = ⁿ√(a^m)      a^(−m/n) = 1 / a^(m/n)      a⁰ = 1 (a ≠ 0)
```

> 0 的正分数指数幂等于 0；0 的负分数指数幂没有意义。

**指数幂的运算法则**（`a > 0`，`b > 0`，r、s ∈ R）：

- `a^r · a^s = a^(r+s)`
- `(a^r)^s = a^(rs)`
- `(ab)^r = a^r · b^r`

### 4.2 指数函数

**定义**：`y = a^x`（`a > 0` 且 `a ≠ 1`）。

| 性质 | a > 1 | 0 < a < 1 |
| --- | --- | --- |
| 定义域 | R | R |
| 值域 | (0, +∞) | (0, +∞) |
| 定点 | 恒过 (0, 1) | 恒过 (0, 1) |
| 单调性 | 在 R 上单调递增 | 在 R 上单调递减 |
| 函数值符号 | x > 0 时 y > 1；x < 0 时 0 < y < 1 | x > 0 时 0 < y < 1；x < 0 时 y > 1 |

**比较大小的策略**：

1. 同底不同指：用单调性。
2. 同指不同底：用图象（在 y 轴右侧"底大图高"）。
3. 底与指数都不同：插入中间量 1（或 0）搭桥。

### 4.3 对数

**定义**：若 `a^x = N`（`a > 0` 且 `a ≠ 1`，`N > 0`），则 `x = log_a N`。这里 a 叫底数，N 叫真数。

> 真数必须大于零！`log_a (−2)` 无意义。

**特殊对数**：常用对数 `lg N = log₁₀ N`；自然对数 `ln N = log_e N`（e ≈ 2.71828）。

**对数恒等式**：

- `a^(log_a N) = N`（a > 0，a ≠ 1，N > 0）
- `log_a a^x = x`
- `log_a 1 = 0`，`log_a a = 1`

**运算律**（`a > 0`，`a ≠ 1`，`M > 0`，`N > 0`）：

```
log_a(MN) = log_a M + log_a N
log_a(M/N) = log_a M − log_a N
log_a M^n = n·log_a M   (n ∈ R)
```

> 注意：`log_a(M + N) ≠ log_a M + log_a N`；`log_a M² = 2log_a M` 要求 M > 0，而 `log_a M² = 2log_a |M|` 才对 M ≠ 0 成立。

**换底公式**：`log_a b = log_c b / log_c a`（a、b、c 均为正数且不等于 1）。

常用推论：`log_a b · log_b a = 1`；`log_a b = 1 / log_b a`；`log_(a^m) b^n = (n/m) log_a b`。

### 4.4 对数函数

**定义**：`y = log_a x`（`a > 0` 且 `a ≠ 1`）。

| 性质 | a > 1 | 0 < a < 1 |
| --- | --- | --- |
| 定义域 | (0, +∞) | (0, +∞) |
| 值域 | R | R |
| 定点 | 恒过 (1, 0) | 恒过 (1, 0) |
| 单调性 | 在 (0, +∞) 上递增 | 在 (0, +∞) 上递减 |
| 函数值符号 | 0 < x < 1 时 y < 0；x > 1 时 y > 0 | 0 < x < 1 时 y > 0；x > 1 时 y < 0 |

`y = a^x` 与 `y = log_a x` 互为反函数，图象关于直线 `y = x` 对称。

### 4.5 函数的应用（二）

**函数的零点**：使 `f(x) = 0` 的实数 x 叫函数 f(x) 的零点。等价说法：f(x) 的零点 ⟺ 方程 f(x) = 0 的根 ⟺ 图象与 x 轴交点的横坐标。

**零点存在定理**：若 f(x) 在闭区间 `[a, b]` 上的图象是连续不断的一条曲线，且 `f(a)·f(b) < 0`，则存在 `c ∈ (a, b)` 使 `f(c) = 0`。

> 注意两点：① 定理只保证"存在"，不保证唯一；② 若 f(x) 同时是单调函数，则零点唯一。

**二分法**：对在 `[a, b]` 上连续且 `f(a)·f(b) < 0` 的函数，反复取中点并判断符号，逐步逼近零点。

**函数模型的增长差异**（x → +∞ 时）：`log_a x` 增长最慢，`x^n` 次之，`a^x` 增长最快（a > 1）。

| x | y = log₂x | y = x² | y = 2^x |
| --- | --- | --- | --- |
| 2 | 1 | 4 | 4 |
| 4 | 2 | 16 | 16 |
| 10 | ≈3.32 | 100 | 1024 |

可见 `y = x²` 与 `y = 2^x` 在 x = 2 和 x = 4 处相等，此后指数函数迅速反超。

## 三、典型例题

### 例 1（分数指数幂与根式化简）

计算：(1) `(8/27)^(−2/3)`；(2) `√(3 − 2√2)`。

**解析**：

(1) `8/27 = (2/3)³`，故 `(8/27)^(−2/3) = ((2/3)³)^(−2/3) = (2/3)^(−2) = (3/2)² = 9/4`。

(2) `3 − 2√2 = (√2)² − 2√2 + 1 = (√2 − 1)²`，故 `√(3 − 2√2) = |√2 − 1| = √2 − 1`。

> 提醒：开偶次方后必须取绝对值，最后再看被开方数是否非负来决定去绝对值的方式。

### 例 2（指数式与对数式的互化）

(1) 把 `2^x = 5` 化为对数式；(2) 把 `log_3 9 = 2` 化为指数式。

**解析**：(1) `x = log_2 5`；(2) `3² = 9`。

**方法总结**：`a^x = N ⟺ x = log_a N`，底数不变，"指数变对数，指数即对数值"。

### 例 3（对数运算）

计算：(1) `lg 25 + lg 4`；(2) `log_2 6 − log_2 3 + log_2 8`；(3) `(lg 2)² + lg 2 · lg 5 + lg 5`。

**解析**：

(1) `lg 25 + lg 4 = lg(25 × 4) = lg 100 = 2`。

(2) `log_2 6 − log_2 3 = log_2(6/3) = log_2 2 = 1`；`log_2 8 = 3`。故原式 `= 1 + 3 = 4`。

(3) 提取公因式：

`(lg 2)² + lg 2 · lg 5 + lg 5 = lg 2(lg 2 + lg 5) + lg 5 = lg 2 · lg 10 + lg 5 = lg 2 + lg 5 = 1`

### 例 4（指数函数比较大小）

比较大小：(1) `1.7^2.5` 与 `1.7^3`；(2) `0.8^(−0.1)` 与 `0.8^(−0.2)`。

**解析**：

(1) 底数 `1.7 > 1`，函数递增，又 `2.5 < 3`，故 `1.7^2.5 < 1.7^3`。

(2) 底数 `0 < 0.8 < 1`，函数递减，又 `−0.1 > −0.2`，故 `0.8^(−0.1) < 0.8^(−0.2)`。

### 例 5（对数函数比较大小）

比较 `log_2 3`、`log_3 2`、`log_(1/2) 3` 的大小。

**解析**：与中间量 0、1 比较搭桥。

- `log_2 3 > log_2 2 = 1`；
- `log_3 1 = 0 < log_3 2 < log_3 3 = 1`；
- 底数 `1/2 < 1`，函数递减，真数 `3 > 1`，故 `log_(1/2) 3 < log_(1/2) 1 = 0`。

所以 `log_(1/2) 3 < log_3 2 < log_2 3`。

### 例 6（对数型复合函数的单调区间与值域）

求函数 `y = log_(1/2)(x² − 2x)` 的单调递增区间与值域。

**解析**：先求定义域：`x² − 2x > 0`，即 `x < 0 或 x > 2`。

令 `u = x² − 2x = (x − 1)² − 1`，外层 `y = log_(1/2) u` 在 `(0, +∞)` 上单调递减。

- 在 `(−∞, 0)` 上 u 递减，由"同增异减"复合函数递增；
- 在 `(2, +∞)` 上 u 递增，复合函数递减。

所以单调递增区间为 `(−∞, 0)`。

求值域：当 `x < 0 或 x > 2` 时，`u = x² − 2x` 可取遍所有正数（如 x 靠近 0 的左侧时 u → 0⁺，x → −∞ 时 u → +∞），故 `y = log_(1/2) u` 可取遍一切实数。

所以值域为 R。

### 例 7（零点存在定理证明）

证明函数 `f(x) = lg x + x − 3` 在区间 `(2, 3)` 内存在零点。

**证明**：f(x) 在 `[2, 3]` 上的图象是连续不断的曲线。

`f(2) = lg 2 + 2 − 3 = lg 2 − 1 < 0`（因为 `lg 2 < lg 10 = 1`）；
`f(3) = lg 3 + 3 − 3 = lg 3 > 0`（因为 `lg 3 > lg 1 = 0`）。

所以 `f(2) · f(3) < 0`，由零点存在定理，存在 `c ∈ (2, 3)` 使 `f(c) = 0`，即 f(x) 在 (2, 3) 内存在零点。

### 例 8（零点个数）

求函数 `f(x) = 2^x + x − 4` 的零点个数。

**解析**：`y = 2^x` 与 `y = x` 在 R 上都单调递增，故 f(x) 在 R 上单调递增，零点至多一个。

`f(1) = 2 + 1 − 4 = −1 < 0`，`f(2) = 4 + 2 − 4 = 2 > 0`，故零点在 `(1, 2)` 内。

所以 f(x) **恰有一个**零点。

**方法总结**：判断零点个数 = "单调性定个数 + 零点存在定理定存在"。

### 例 9（对数方程与换底公式）

已知 `log_2 3 = a`，用 a 表示 `log_3 12`。

**解析**：由换底公式，

`log_3 12 = log_2 12 / log_2 3 = (log_2 3 + log_2 4) / log_2 3 = (a + 2) / a`

所以 `log_3 12 = (a + 2)/a = 1 + 2/a`。

### 例 10（指数模型的实际应用）

某药物在体内的残留量每经过 1 天变为原来的 60%。若初始残留量为 500 mg，问至少经过多少天残留量低于 100 mg？

**解析**：设经过 n 天后残留量为 `500 × 0.6ⁿ`，需

`500 × 0.6ⁿ < 100`，即 `0.6ⁿ < 0.2`

两边取对数（底数 0.6 < 1，不等号反向）：

`n > log_(0.6) 0.2 = lg 0.2 / lg 0.6 ≈ (−0.6990)/(−0.2218) ≈ 3.15`

检验：`500 × 0.6³ = 108 > 100`，`500 × 0.6⁴ = 64.8 < 100`。

所以至少经过 **4 天**。

## 四、易错点清单

1. **偶次方根忘取绝对值**：`√(a²) = |a|`，不是 a。
2. **忽略分数指数幂的底数限制**：`a^(m/n)` 中要求 `a > 0`；`(−8)^(1/3) = −2` 成立，但 `(−8)^(2/6)` 在教材规定下不讨论。
3. **真数必须为正**：求对数型函数定义域时先列 `真数 > 0`，这是最常见的丢分点。
4. **误用运算律**：`log_a(M + N) ≠ log_a M · log_a N`；`lg 2 + lg 5 = lg 10 = 1` 但 `lg(2 + 5) = lg 7 ≠ 1`。
5. **底数含参不讨论**：指数、对数函数的单调性由底数决定，底数含参时必须分 `a > 1` 与 `0 < a < 1`。
6. **零点存在定理乱用**：`f(a)·f(b) < 0` 只保证存在零点，且要求函数图象连续；反过来 `f(a)·f(b) > 0` 不能说明没有零点。
7. **对数方程不检验**：解对数方程后必须代回检验真数是否大于零（可能产生增根）。
8. **单调区间超出定义域**：对数型复合函数必须先求定义域再讨论单调性（例如例 6 中不能写 `(−∞, 1)`）。

## 五、自测题（限时 45 分钟）

1. 计算 `(27/8)^(2/3)`。
2. 计算 `√(5 − 2√6)`。
3. 把 `log_4 16 = 2` 化为指数式。
4. 计算 `log_3 18 − log_3 2`。
5. 计算 `lg 4 + lg 25 + 2^(log_2 5)`。
6. 比较 `0.9^1.1` 与 `0.9^1.2` 的大小。
7. 比较 `log_2 5` 与 2 的大小。
8. 求函数 `y = lg(x² − 3x + 2)` 的定义域。
9. 判断 `f(x) = ln x + 2x − 6` 的零点所在的一个整数区间。
10. 比较 `a = 2^0.3`、`b = 0.3²`、`c = log_2 0.3` 的大小。

## 六、自测题答案与解析

1. `27/8 = (3/2)³`，故 `(27/8)^(2/3) = (3/2)² = 9/4`。
2. `5 − 2√6 = (√3)² − 2√3√2 + (√2)² = (√3 − √2)²`，故原式 `= |√3 − √2| = √3 − √2`。
3. `4² = 16`。
4. `log_3 18 − log_3 2 = log_3(18/2) = log_3 9 = 2`。
5. `lg 4 + lg 25 = lg 100 = 2`；由对数恒等式 `2^(log_2 5) = 5`。原式 `= 2 + 5 = 7`。
6. 底数 `0 < 0.9 < 1`，函数递减，又 `1.1 < 1.2`，故 `0.9^1.1 > 0.9^1.2`。
7. `log_2 5 > log_2 4 = 2`。
8. 需 `x² − 3x + 2 > 0`，即 `(x − 1)(x − 2) > 0`，定义域为 `{x | x < 1 或 x > 2}`。
9. `f(2) = ln 2 + 4 − 6 = ln 2 − 2 ≈ −1.31 < 0`，`f(3) = ln 3 + 6 − 6 = ln 3 ≈ 1.10 > 0`，且 f(x) 在 `(0, +∞)` 上连续且单调递增，故零点在 `(2, 3)` 内。
10. `a = 2^0.3 ∈ (1, 2)`；`b = 0.3² = 0.09 ∈ (0, 1)`；`c = log_2 0.3 < log_2 1 = 0`。所以 `c < b < a`。
