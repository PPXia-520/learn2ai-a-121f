## 二、知识梳理

### 5.1 任意角与弧度制

- **任意角**：按逆时针方向旋转形成的角叫正角，顺时针为负角，不旋转为零角。
- **终边相同的角**：与角 α 终边相同的角的集合为 `S = {β | β = α + k·360°, k ∈ Z}`（用弧度制写作 `β = α + 2kπ`）。
- **象限角**：角的终边（除端点外）落在第几象限，就叫第几象限角；终边落在坐标轴上的角不属于任何象限。

**弧度制**：长度等于半径长的圆弧所对的圆心角叫 1 弧度的角，记作 1 rad。

- 互化：`180° = π rad`，`1° = π/180 rad ≈ 0.01745 rad`，`1 rad = (180/π)° ≈ 57.30°`。
- **弧长公式**：`l = |α| · r`（α 为弧度数）。
- **扇形面积公式**：`S = ½ l r = ½ |α| r²`。

### 5.2 三角函数的概念

设角 α 的终边上任意一点 `P(x, y)`（异于原点），`r = √(x² + y²)`，则

```
sin α = y/r      cos α = x/r      tan α = y/x (x ≠ 0)
```

**符号规律**（"一全正、二正弦、三正切、四余弦"）：

| 象限 | sin α | cos α | tan α |
| --- | --- | --- | --- |
| 第一象限 | + | + | + |
| 第二象限 | + | − | − |
| 第三象限 | − | − | + |
| 第四象限 | − | + | − |

**特殊角三角函数值**：

| α | 0 | π/6 | π/4 | π/3 | π/2 |
| --- | --- | --- | --- | --- | --- |
| sin α | 0 | 1/2 | √2/2 | √3/2 | 1 |
| cos α | 1 | √3/2 | √2/2 | 1/2 | 0 |
| tan α | 0 | √3/3 | 1 | √3 | 不存在 |

**同角三角函数的基本关系**：

- 平方关系：`sin²α + cos²α = 1`
- 商数关系：`tan α = sin α / cos α`（`α ≠ π/2 + kπ`）

> 已知一个三角函数值求另外两个时，必须由角的**象限**确定符号。

### 5.3 诱导公式

| 公式 | 内容 |
| --- | --- |
| 公式一 | `sin(α + 2kπ) = sinα`，`cos(α + 2kπ) = cosα`，`tan(α + 2kπ) = tanα` |
| 公式二 | `sin(π + α) = −sinα`，`cos(π + α) = −cosα`，`tan(π + α) = tanα` |
| 公式三 | `sin(−α) = −sinα`，`cos(−α) = cosα`，`tan(−α) = −tanα` |
| 公式四 | `sin(π − α) = sinα`，`cos(π − α) = −cosα`，`tan(π − α) = −tanα` |
| 公式五 | `sin(π/2 − α) = cosα`，`cos(π/2 − α) = sinα` |
| 公式六 | `sin(π/2 + α) = cosα`，`cos(π/2 + α) = −sinα` |

**记忆口诀**："奇变偶不变，符号看象限"。

- "奇变偶不变"指把角写成 `k·π/2 ± α` 时，k 为奇数则函数名改变（sin ↔ cos），k 为偶数则函数名不变。
- "符号看象限"指把 α 视为锐角，判断原角所在象限内原函数的符号。

### 5.4 三角函数的图象与性质

| 性质 | y = sin x | y = cos x | y = tan x |
| --- | --- | --- | --- |
| 定义域 | R | R | {x | x ≠ π/2 + kπ} |
| 值域 | [−1, 1] | [−1, 1] | R |
| 最小正周期 | 2π | 2π | π |
| 奇偶性 | 奇函数 | 偶函数 | 奇函数 |
| 单调递增区间 | [−π/2 + 2kπ, π/2 + 2kπ] | [−π + 2kπ, 2kπ] | (−π/2 + kπ, π/2 + kπ) |
| 单调递减区间 | [π/2 + 2kπ, 3π/2 + 2kπ] | [2kπ, π + 2kπ] | 无 |
| 对称中心 | (kπ, 0) | (π/2 + kπ, 0) | (kπ/2, 0) |
| 对称轴 | x = π/2 + kπ | x = kπ | 无 |

**y = Asin(ωx + φ) 的四个参数**（A > 0，ω > 0）：

- 振幅 A：值域为 `[−A, A]`。
- 周期 `T = 2π/ω`，频率 `f = 1/T = ω/(2π)`。
- 相位 `ωx + φ`，初相 φ。

**"五点法"作图**：令 `ωx + φ` 依次取 `0, π/2, π, 3π/2, 2π`，解出对应的 x 并计算 y，得到五个关键点。

**图象变换**：由 `y = sin x` 到 `y = Asin(ωx + φ)` 有两条路径。

| 路径 | 步骤 | 注意 |
| --- | --- | --- |
| 先平移后伸缩 | sin x →(左移 φ)→ sin(x + φ) →(横坐标缩为 1/ω)→ sin(ωx + φ) →(纵坐标乘 A)→ Asin(ωx + φ) | 平移量是 φ |
| 先伸缩后平移 | sin x →(横坐标缩为 1/ω)→ sin(ωx) →(左移 φ/ω)→ sin(ωx + φ) →(纵坐标乘 A)→ Asin(ωx + φ) | **平移量是 φ/ω** |

> 高频易错：先伸缩后平移时，平移量必须是 φ/ω，而不是 φ。

### 5.5 三角恒等变换

**两角和与差公式**：

```
sin(α ± β) = sinα·cosβ ± cosα·sinβ
cos(α ± β) = cosα·cosβ ∓ sinα·sinβ
tan(α ± β) = (tanα ± tanβ) / (1 ∓ tanα·tanβ)
```

**二倍角公式**：

```
sin 2α = 2 sinα·cosα
cos 2α = cos²α − sin²α = 2cos²α − 1 = 1 − 2sin²α
tan 2α = 2tanα / (1 − tan²α)
```

**降幂公式**（由二倍角公式变形得到，处理平方项的关键）：

```
sin²α = (1 − cos 2α)/2      cos²α = (1 + cos 2α)/2
```

**辅助角公式**：`a·sinx + b·cosx = √(a² + b²)·sin(x + φ)`，其中 `tanφ = b/a`（φ 的象限由 a、b 的符号确定）。

**常用变形技巧**：切化弦、1 的代换（`1 = sin²α + cos²α`）、通分、构造平方差/完全平方。

### 5.6 函数 y = Asin(ωx + φ)

由图象求解析式的步骤：

```
① 由最大值、最小值求 A（A = (最大值 − 最小值)/2）
② 由相邻最高点与最低点的横坐标差求半周期，进而求 ω
③ 代入一个已知点（优先最高点或最低点）求 φ，并注意 |φ| 的范围
```

## 三、典型例题

### 例 1（终边相同的角）

把 `α = −1500°` 化为 `β + k·360°` 的形式（其中 `0° ≤ β < 360°`，k ∈ Z），并判断 α 是第几象限角。

**解析**：`−1500° = −1500° + 5 × 360° − 5 × 360° = 300° − 5 × 360°`，即 `β = 300°`，`k = −5`。

因为 `270° < 300° < 360°`，所以 α 是**第四象限角**。

### 例 2（弧度制与扇形）

已知扇形的半径为 6 cm，圆心角为 120°，求它的弧长与面积。

**解析**：`120° = 120 × π/180 = 2π/3`（rad）。

弧长 `l = |α|r = (2π/3) × 6 = 4π ≈ 12.57`（cm）。

面积 `S = ½ l r = ½ × 4π × 6 = 12π ≈ 37.70`（cm²）。

### 例 3（三角函数的定义）

已知角 α 的终边经过点 `P(−3, 4)`，求 `sinα`、`cosα`、`tanα`。

**解析**：`r = √((−3)² + 4²) = √25 = 5`。

`sinα = 4/5`，`cosα = −3/5`，`tanα = 4/(−3) = −4/3`。

### 例 4（同角三角函数关系）

已知 `sinα = 3/5`，且 α 是第二象限角，求 `cosα` 与 `tanα`。

**解析**：由 `sin²α + cos²α = 1` 得 `cos²α = 1 − 9/25 = 16/25`，故 `cosα = ±4/5`。

因为 α 是第二象限角，`cosα < 0`，所以 `cosα = −4/5`。

`tanα = sinα/cosα = (3/5)/(−4/5) = −3/4`。

### 例 5（诱导公式与整体代换）

已知 `cos(π/6 − α) = 1/3`，求 `sin(α + π/3)`。

**解析**：注意到 `α + π/3 = π/2 − (π/6 − α)`，由公式五：

`sin(α + π/3) = sin(π/2 − (π/6 − α)) = cos(π/6 − α) = 1/3`

**方法总结**：诱导公式题的关键是"凑角"，把目标角用已知角表示出来。

### 例 6（三角函数的图象与性质）

求函数 `y = 2sin(2x − π/3)` 的最小正周期、最大值、单调递增区间、对称轴与对称中心。

**解析**：

- 周期：`T = 2π/|ω| = 2π/2 = π`。
- 最大值：`2`（当 `sin(2x − π/3) = 1` 时）。
- 单调递增区间：令 `−π/2 + 2kπ ≤ 2x − π/3 ≤ π/2 + 2kπ`，解得 `−π/12 + kπ ≤ x ≤ 5π/12 + kπ`，即 `[−π/12 + kπ, 5π/12 + kπ] (k ∈ Z)`。
- 对称轴：令 `2x − π/3 = π/2 + kπ`，得 `x = 5π/12 + kπ/2 (k ∈ Z)`。
- 对称中心：令 `2x − π/3 = kπ`，得 `x = π/6 + kπ/2`，中心为 `(π/6 + kπ/2, 0) (k ∈ Z)`。

### 例 7（图象变换）

说明如何由 `y = sin x` 的图象得到 `y = 3sin(2x + π/3)` 的图象。

**解析**：

**方法一（先平移后伸缩）**：

1. 把 `y = sin x` 的图象向左平移 `π/3` 个单位，得 `y = sin(x + π/3)`；
2. 把横坐标缩短为原来的 `1/2`（纵坐标不变），得 `y = sin(2x + π/3)`；
3. 把纵坐标伸长为原来的 3 倍（横坐标不变），得 `y = 3sin(2x + π/3)`。

**方法二（先伸缩后平移）**：

1. 把横坐标缩短为原来的 `1/2`，得 `y = sin 2x`；
2. 向左平移 `π/6` 个单位（**不是 π/3**），得 `y = sin 2(x + π/6) = sin(2x + π/3)`；
3. 把纵坐标伸长为原来的 3 倍，得 `y = 3sin(2x + π/3)`。

### 例 8（由图象求解析式）

已知函数 `y = Asin(ωx + φ)`（A > 0，ω > 0，|φ| < π/2）的图象上相邻的最高点为 `(π/6, 3)`，最低点为 `(2π/3, −3)`，求其解析式。

**解析**：

① 由最高点纵坐标得 `A = 3`。

② 相邻最高点与最低点的横坐标之差为半个周期：`T/2 = 2π/3 − π/6 = π/2`，故 `T = π`，`ω = 2π/T = 2`。

③ 最高点处 `sin` 取到 1，即 `2 × π/6 + φ = π/2 + 2kπ`，得 `φ = π/6 + 2kπ`。由 `|φ| < π/2` 取 `φ = π/6`。

所以 `y = 3sin(2x + π/6)`。

### 例 9（三角恒等变换 · 平方关系与立方和）

已知 `sinα + cosα = 1/2`，求 `sin 2α` 与 `sin³α + cos³α`。

**解析**：两边平方得

`sin²α + 2sinα·cosα + cos²α = 1/4`，即 `1 + sin 2α = 1/4`

故 `sin 2α = −3/4`。

再由立方和公式：

`sin³α + cos³α = (sinα + cosα)(sin²α − sinα·cosα + cos²α) = (1/2) × (1 − (−3/8)) = (1/2) × (11/8) = 11/16`

### 例 10（两角和公式的逆用）

求 `(1 + tan 15°)/(1 − tan 15°)` 的值。

**解析**：对照正切和角公式 `tan(45° + 15°) = (tan 45° + tan 15°)/(1 − tan 45°·tan 15°)`，

因为 `tan 45° = 1`，所以原式 `= tan(45° + 15°) = tan 60° = √3`。

**方法总结**：看到"1 ± tanα"要立刻联想到 `tan 45° = 1`，这是公式逆用的典型信号。

### 例 11（辅助角公式求最值）

求函数 `y = sin x + √3 cos x` 的最大值与最小正周期。

**解析**：由辅助角公式，

`y = 2 × (½ sin x + (√3/2) cos x) = 2 sin(x + π/3)`

所以最大值为 2，最小正周期为 `2π`。

## 四、易错点清单

1. **角度与弧度混用**：`sin 30` 与 `sin 30°` 完全不同；公式中 α 一律用弧度制。
2. **忽略象限导致符号错误**：由 `sin²α + cos²α = 1` 解出 cosα 后必须用象限定号。
3. **忽视 tanα 的存在条件**：`tanα` 在 `α = π/2 + kπ` 处无定义，涉及切函数时要讨论。
4. **图象变换平移量算错**：先伸缩后平移时，平移量是 `φ/ω`。例 7 中若写成平移 `π/3` 就错了。
5. **单调区间写错**：求 `y = Asin(ωx + φ)` 的单调区间时，要把 `ωx + φ` 整体代入 `y = sin u` 的单调区间再解不等式；若 `ω < 0` 先用诱导公式化为正。
6. **周期公式漏绝对值**：`T = 2π/|ω|`，ω 为负时也要取正。
7. **辅助角公式的 φ 取错**：`a sinx + b cosx = √(a²+b²) sin(x+φ)` 中 `tan φ = b/a`，φ 的象限由点 (a, b) 所在象限确定。
8. **二倍角公式三种形式记混**：`cos 2α` 的三形式要按题目需要选择，处理平方项时用降幂形式。

## 五、自测题（限时 45 分钟）

1. 把 `−60°` 化为弧度。
2. 把 `3π/4` 化为角度。
3. 写出与 `30°` 终边相同的角的集合。
4. 已知角 α 的终边经过点 `P(1, −√3)`，求 `sinα`、`cosα`、`tanα`。
5. 已知 `cosα = −5/13`，且 α 是第三象限角，求 `sinα`。
6. 计算 `sin(−π/6) + cos(2π/3) + tan(−π/4)`。
7. 求 `sin 75°` 的值。
8. 已知 `sinα = 3/5`，`α ∈ (π/2, π)`，求 `sin 2α` 与 `cos 2α`。
9. 求函数 `y = 3sin(2x + π/4)` 的最小正周期与最大值。
10. 说明如何由 `y = sin x` 的图象得到 `y = sin(2x − π/4)` 的图象。

## 六、自测题答案与解析

1. `−60° = −60 × π/180 = −π/3`。
2. `3π/4 = (3/4) × 180° = 135°`。
3. `{β | β = 30° + k·360°, k ∈ Z}`。
4. `r = √(1² + (−√3)²) = √4 = 2`。`sinα = −√3/2`，`cosα = 1/2`，`tanα = −√3`。
5. `sin²α = 1 − cos²α = 1 − 25/169 = 144/169`，故 `sinα = ±12/13`。α 在第三象限，`sinα < 0`，所以 `sinα = −12/13`。
6. `sin(−π/6) = −1/2`，`cos(2π/3) = −1/2`，`tan(−π/4) = −1`。原式 `= −1/2 − 1/2 − 1 = −2`。
7. `sin 75° = sin(45° + 30°) = sin45°cos30° + cos45°sin30° = (√2/2)(√3/2) + (√2/2)(1/2) = (√6 + √2)/4`。
8. α 在第二象限，`cosα = −√(1 − 9/25) = −4/5`。

   `sin 2α = 2 sinα cosα = 2 × (3/5) × (−4/5) = −24/25`；

   `cos 2α = 1 − 2sin²α = 1 − 2 × 9/25 = 7/25`。
9. `T = 2π/2 = π`；最大值为 3（当 `sin(2x + π/4) = 1` 时取得）。
10. 两种说法都可以：

    - 先把横坐标缩短为原来的 `1/2`，得 `y = sin 2x`；再向右平移 `π/8` 个单位，得 `y = sin 2(x − π/8) = sin(2x − π/4)`。
    - 或先向右平移 `π/4` 个单位，得 `y = sin(x − π/4)`；再把横坐标缩短为原来的 `1/2`，得 `y = sin(2x − π/4)`。
