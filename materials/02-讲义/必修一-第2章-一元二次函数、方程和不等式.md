# 必修第一册 · 第 2 章 一元二次函数、方程和不等式

> 建议课时：10 课时　｜　对应进度：第 4—5 周  
> 本章是"三个二次"（二次函数、一元二次方程、一元二次不等式）相互转化的入门，也是后续函数、导数中讨论参数的基础

## 一、知识结构

```
一元二次函数、方程和不等式
├─ 等式与不等式的性质
│  ├─ 作差比较法（a − b > 0 ⟺ a > b）
│  └─ 不等式的基本性质（对称性、传递性、可加性、可乘性、同向可加性）
├─ 基本不等式
│  ├─ √(ab) ≤ (a + b)/2（a > 0，b > 0，当且仅当 a = b 取等）

│  └─ 使用条件：一正、二定、三相等
└─ 三个二次
   ├─ 二次函数 y = ax² + bx + c
   ├─ 一元二次方程 ax² + bx + c = 0（判别式、韦达定理）
   └─ 一元二次不等式 ax² + bx + c > 0 / < 0（解集与图象、判别式的关系）
```

## 二、知识梳理

### 2.1 等式性质与不等式性质

**作差比较法**（比较大小的通法）：

```
作差 a − b → 变形（因式分解 / 配方 / 通分）→ 判断符号 → 得出结论
```

**不等式的基本性质**（注意每条的使用前提）：

| 性质 | 表达式 | 前提提醒 |
| --- | --- | --- |
| 对称性 | `a > b ⟺ b < a` | — |
| 传递性 | `a > b, b > c ⟹ a > c` | — |
| 可加性 | `a > b ⟺ a + c > b + c` | 移项的依据 |
| 可乘性 | `a > b, c > 0 ⟹ ac > bc`；`a > b, c < 0 ⟹ ac < bc` | **c 的符号决定不等号方向** |
| 同向可加 | `a > b, c > d ⟹ a + c > b + d` | 只能同向相加 |
| 同向同正可乘 | `a > b > 0, c > d > 0 ⟹ ac > bd` | 必须都是正数 |
| 可乘方 | `a > b > 0 ⟹ aⁿ > bⁿ (n ∈ N*)` | 必须都是正数 |
| 倒数 | `a > b > 0 ⟹ 1/a < 1/b` | 必须都是正数 |

> 高频陷阱：`a > b` 不能推出 `ac² > bc²`（c 可能为 0），也不能推出 `1/a < 1/b`（符号未知）。

### 2.2 基本不等式

**基本不等式**：若 `a > 0, b > 0`，则

```
√(ab) ≤ (a + b) / 2，当且仅当 a = b 时取等号
```

其中 `(a + b)/2` 叫算术平均数，`√(ab)` 叫几何平均数。几何意义：圆内直径上的半弦不超过半径。

**常用变形**：

- `a + b ≥ 2√(ab)`（积为定值时，和取最小）
- `ab ≤ ((a + b)/2)²`（和为定值时，积取最大）
- 若 a、b 同号，则 `a/b + b/a ≥ 2`（a、b 同正时取等）

**使用条件"一正、二定、三相等"**：

1. **一正**：各项必须为正（否则需先变形，如讨论 `x < 0` 时提取负号）。
2. **二定**：和或积中有一个是定值。
3. **三相等**：验证取等条件能否成立（这是最容易漏的一步）。

**常用技巧**：

- 配凑：`x + 4/(x−1) = (x−1) + 4/(x−1) + 1`
- 拆项：把定值拆成与变量匹配的形式
- "1" 的代换：把 `1` 写成已知的等式（如 `(x+y)/4`）后与目标式相乘
- 消元：用已知等式把双变量化为单变量

### 2.3 二次函数与一元二次方程、不等式

设 `a > 0`，记 `Δ = b² − 4ac`，则 `ax² + bx + c > 0` 与 `ax² + bx + c < 0` 的解集：

| 判别式 | 方程 ax²+bx+c=0 的根 | ax² + bx + c > 0 的解集 | ax² + bx + c < 0 的解集 |
| --- | --- | --- | --- |
| Δ > 0 | 两根 x₁ < x₂ | `{x | x < x₁ 或 x > x₂}` | `{x | x₁ < x < x₂}` |
| Δ = 0 | 重根 x₁ = x₂ = −b/(2a) | `{x | x ≠ −b/(2a)}` | ∅ |
| Δ < 0 | 无实根 | R | ∅ |

若 `a < 0`，先在不等式两边同乘 −1（不等号反向）化为 `a > 0` 的情形。

**韦达定理**：若 `ax² + bx + c = 0` 的两根为 x₁、x₂，则 `x₁ + x₂ = −b/a`，`x₁x₂ = c/a`。

**解含参一元二次不等式的讨论顺序**（固定套路）：

```
① 二次项系数是否含参 → 分 a = 0 与 a ≠ 0
② 开口方向 → 分 a > 0 与 a < 0（或统一化正）
③ 判别式 → 分 Δ > 0、Δ = 0、Δ < 0
④ 两根大小 → 分 x₁ < x₂、x₁ = x₂、x₁ > x₂
```

**分式不等式**：`f(x)/g(x) ≥ 0 ⟺ f(x)·g(x) ≥ 0 且 g(x) ≠ 0`。切记**不能直接去分母**，因为分母符号未知。

**恒成立问题**的三种处理：

1. 对 ∀x ∈ R，`ax² + bx + c > 0` 恒成立 ⟺ `a > 0 且 Δ < 0`。
2. 分离参数：化为 `a > f(x)` 恒成立 ⟺ `a > f(x) 的最大值`。
3. 最值法：转化为求函数在区间上的最小值（或最大值）。

## 三、典型例题

### 例 1（作差比较法）

比较 `(x² + 1)²` 与 `x⁴ + x² + 1` 的大小。

**解析**：作差

`(x² + 1)² − (x⁴ + x² + 1) = x⁴ + 2x² + 1 − x⁴ − x² − 1 = x² ≥ 0`

所以 `(x² + 1)² ≥ x⁴ + x² + 1`，当且仅当 `x = 0` 时取等号。

### 例 2（不等式性质的辨析）

判断下列命题的真假，并说明理由：

(1) 若 `a > b`，则 `ac² > bc²`；  
(2) 若 `a > b > 0`，`c > d > 0`，则 `ac > bd`；  
(3) 若 `a > b`，则 `1/a < 1/b`；  
(4) 若 `a > b`，`c > d`，则 `a − d > b − c`。

**解析**：

(1) **假**。取 `c = 0`，则 `ac² = bc² = 0`。
(2) **真**。由同向同正可乘性，`ac > bc` 且 `bc > bd`，再由传递性得 `ac > bd`。
(3) **假**。取 `a = 1`，`b = −2`，则 `a > b` 但 `1/a = 1 > −1/2 = 1/b`。
(4) **真**。由 `c > d` 得 `−d > −c`，与 `a > b` 同向相加得 `a − d > b − c`。

### 例 3（基本不等式的直接应用）

已知 `x > 0`，求 `y = x + 4/x` 的最小值，并求取最小值时 x 的值。

**解析**：由基本不等式，`x + 4/x ≥ 2√(x · 4/x) = 4`。

取等条件：`x = 4/x`，即 `x² = 4`，结合 `x > 0` 得 `x = 2`。

所以当 `x = 2` 时，y 取最小值 4。

### 例 4（配凑法）

已知 `x > 1`，求 `y = x + 4/(x − 1)` 的最小值。

**解析**：把 x 拆成 `(x − 1) + 1`：

`y = (x − 1) + 4/(x − 1) + 1`

因为 `x > 1`，所以 `x − 1 > 0`，可用基本不等式：

`(x − 1) + 4/(x − 1) ≥ 2√4 = 4`

取等条件：`x − 1 = 4/(x − 1)`，即 `(x − 1)² = 4`，得 `x = 3`。

所以 `y ≥ 4 + 1 = 5`，当 `x = 3` 时取最小值 5。

**方法总结**：分式与整式相加时，先把整式配成与分母一致的形式，再使用基本不等式。

### 例 5（"1"的代换）

已知 `x > 0`，`y > 0`，且 `x + y = 4`，求 `1/x + 4/y` 的最小值。

**解析**：把 1 代换为 `(x + y)/4`：

`1/x + 4/y = (1/x + 4/y) · (x + y)/4 = (1 + y/x + 4x/y + 4)/4 = (5 + y/x + 4x/y)/4`

由基本不等式 `y/x + 4x/y ≥ 2√4 = 4`（因为 x、y 同正），故

`1/x + 4/y ≥ (5 + 4)/4 = 9/4`

取等条件：`y/x = 4x/y`，即 `y = 2x`，结合 `x + y = 4` 得 `x = 4/3`，`y = 8/3`。

所以最小值为 `9/4`。

### 例 6（消元 + 基本不等式）

已知 `x > 0`，`y > 0`，且 `x + 2y + 2xy = 8`，求 `x + 2y` 的最小值。

**解析**：记 `t = x + 2y`。由基本不等式

`2xy = x · 2y ≤ ((x + 2y)/2)² = t²/4`

代入条件得 `8 = x + 2y + 2xy ≤ t + t²/4`，即 `t² + 4t − 32 ≥ 0`，分解得 `(t + 8)(t − 4) ≥ 0`。

因为 `t > 0`，所以 `t ≥ 4`。

取等条件：`x = 2y`，结合 `x + 2y + 2xy = 8` 得 `x = 2`，`y = 1`，此时 `t = 4`。

所以 `x + 2y` 的最小值为 4。

### 例 7（含参一元二次不等式 · 分类讨论）

解关于 x 的不等式 `x² − (a + 1)x + a < 0`。

**解析**：左边分解因式得 `(x − 1)(x − a) < 0`。

- 当 `a > 1` 时，解集为 `{x | 1 < x < a}`；
- 当 `a = 1` 时，不等式变为 `(x − 1)² < 0`，解集为 ∅；
- 当 `a < 1` 时，解集为 `{x | a < x < 1}`。

**方法总结**：能因式分解的含参不等式，分类标准就是**两根的大小**。

### 例 8（分式不等式）

解不等式 `(x − 2)/(x + 1) ≥ 1`。

**解析**：不能直接两边乘 `x + 1`（符号未知），必须先移项通分：

`(x − 2)/(x + 1) − 1 ≥ 0`

`(x − 2 − x − 1)/(x + 1) ≥ 0`，即 `−3/(x + 1) ≥ 0`

因为分子恒为负，故需 `x + 1 < 0`，即 `x < −1`。

所以解集为 `{x | x < −1}`。

### 例 9（恒成立问题）

若对任意实数 x，`x² − ax + 4 > 0` 恒成立，求 a 的取值范围。

**解析**：二次项系数 `1 > 0`，开口向上，故只需判别式 `Δ = a² − 16 < 0`。

解得 `−4 < a < 4`。

**变式**：若改为"存在实数 x 使 `x² − ax + 4 < 0`"，则需 `Δ > 0`，即 `a < −4 或 a > 4`。

## 四、易错点清单

1. **基本不等式忽略"一正"**：`x < 0` 时 `x + 4/x ≤ −4`（最大值为 −4），不能直接用 `≥ 4`。
2. **忘记验证取等**：写"最小值"前必须说明等号能取到，否则最小值可能取不到。
3. **两边同乘一个式子**：分式不等式、含参不等式两边同乘时，必须先确定符号。
4. **解集写成等式**：`x² − 5x + 6 < 0` 的解集是 `{x | 2 < x < 3}`，不是 `{x | x = 2 或 x = 3}`。
5. **含参不等式忘记讨论 a = 0**：二次项系数含参时，先讨论它是否为零（此时退化为一次不等式）。
6. **两根大小不讨论**：因式分解后若两根含参，必须分 `x₁ < x₂`、相等、`x₁ > x₂` 三种情况。
7. **恒成立与存在性混淆**：`ax² + bx + c > 0` 恒成立需 `a > 0 且 Δ < 0`，而"存在 x 使其成立"的条件完全不同。

4. 已知 `x < 0`，求 `g(x) = x + 4/x` 的最大值。
5. 已知 `a > 0`，`b > 0`，且 `a + 2b = 2`，求 `1/a + 1/b` 的最小值。
6. 解不等式 `x² − 5x + 6 ≤ 0`。
7. 解不等式 `−x² + 2x + 3 > 0`。
8. 解不等式 `(x + 1)/(x − 2) ≤ 0`。
9. 若不等式 `x² + mx + 1 ≥ 0` 对一切实数 x 成立，求 m 的取值范围。

## 六、自测题答案与解析

1. 作差：`x² + 3 − 3x = (x − 3/2)² + 3/4 > 0` 恒成立，故 `x² + 3 > 3x`。
2. **假**。反例：取 `a = 2`，`b = 1`，`c = −1`，则 `a > b` 但 `a/c = −2 < −1 = b/c`。当 `c < 0` 时不等号应反向；当 `c = 0` 时无意义。
3. `2x + 8/x ≥ 2√16 = 8`，取等条件 `2x = 8/x`，即 `x² = 4`，`x = 2`。最小值 8。
4. 因为 `x < 0`，则 `−x > 0`，`x + 4/x = −[(−x) + 4/(−x)] ≤ −2√4 = −4`。取等条件 `−x = 4/(−x)`，即 `x = −2`。最大值 −4。
5. 由 `a + 2b = 2` 得 `(a + 2b)/2 = 1`，用它作"1"的代换：

   `1/a + 1/b = (1/a + 1/b)·(a + 2b)/2 = (1 + 2b/a + a/b + 2)/2 = (3 + 2b/a + a/b)/2 ≥ (3 + 2√2)/2`

   取等条件 `2b/a = a/b`，即 `a = √2 b`，可解出 `b = 2/(2 + √2)`，`a = 2√2/(2 + √2)`，均为正数。最小值 `(3 + 2√2)/2`。
6. 分解得 `(x − 2)(x − 3) ≤ 0`，解集 `{x | 2 ≤ x ≤ 3}`。
7. 两边乘 −1 得 `x² − 2x − 3 < 0`，分解得 `(x − 3)(x + 1) < 0`，解集 `{x | −1 < x < 3}`。
8. 等价于 `(x + 1)(x − 2) ≤ 0 且 x ≠ 2`，解集 `{x | −1 ≤ x < 2}`。
9. 开口向上，需 `Δ = m² − 4 ≤ 0`，故 `−2 ≤ m ≤ 2`。
10. 左边配方得 `(x − a)² − 1 < 0`，即 `(x − a)² < 1`，故解集为 `{x | a − 1 < x < a + 1}`。
