## 二、知识梳理

### 3.1 函数的概念及其表示

**定义**：设 A、B 是非空实数集，如果按照某种确定的对应关系 f，使对于集合 A 中的**任意**一个数 x，在集合 B 中都存在**唯一确定**的数 y 与之对应，就称 f 为从 A 到 B 的一个函数，记作 `y = f(x), x ∈ A`。

关键词：**任意**（不能有遗漏）、**唯一**（不能一对多）。因此"y² = x"不表示 y 是 x 的函数。

**函数三要素**：

- 定义域：自变量 x 的取值范围 A。
- 对应关系 f：决定 x 到 y 的映射规则。
- 值域：`{f(x) | x ∈ A}`，它是 B 的子集，由定义域与对应关系**唯一确定**。

**判断两个函数是否相同**：定义域相同 **且** 对应关系相同（与用什么字母表示自变量无关）。

**常见区间写法**：`(a, b)` 开区间，`[a, b]` 闭区间，`[a, b)` 半开半闭；`(a, +∞)`、`(−∞, b]`、`R = (−∞, +∞)`。

**求定义域的四条原则**：

| 结构 | 限制条件 |
| --- | --- |
| 分式 `1/g(x)` | `g(x) ≠ 0` |
| 偶次根式 `√(g(x))` | `g(x) ≥ 0` |
| 零次幂 `g(x)⁰` | `g(x) ≠ 0` |
| 实际问题 | 还需符合实际意义（长度 > 0、人数为整数等） |

**求值域的常用方法**：① 观察法；② 配方法（二次型）；③ 分离常数法（`(ax+b)/(cx+d)` 型）；④ 换元法；⑤ 单调性法。

**分段函数**：在定义域的不同子区间上有不同解析式的函数。它是**一个**函数，不是几个函数。求值时必须先判断自变量落在哪一段。

### 3.2 函数的基本性质

**单调性**（严格定义）：设函数 f(x) 的定义域为 I，区间 `D ⊆ I`。若对 D 内**任意** `x₁ < x₂` 都有 `f(x₁) < f(x₂)`，则称 f(x) 在 D 上单调递增；若都有 `f(x₁) > f(x₂)`，则称单调递减。

> 注意：① 必须"任意"，不能用几个特例判断；② 单调区间必须写在定义域内；③ 单调区间之间用"和"或逗号分隔，**不能写成并集**（如 `f(x) = 1/x` 在 `(−∞,0)` 和 `(0,+∞)` 上分别递减，但不能说在 `(−∞,0) ∪ (0,+∞)` 上递减）。

**定义法证明单调性的五步**：

```
① 取值：任取 x₁, x₂ ∈ D 且 x₁ < x₂
② 作差：计算 f(x₁) − f(x₂)
③ 变形：因式分解 / 通分 / 配方 / 有理化
④ 定号：判断差的正负
⑤ 结论：说明 f(x) 在 D 上单调递增（或递减）
```

**复合函数单调性**（"同增异减"）：设 `y = f(u)`，`u = g(x)`，则

| 外层 f | 内层 g | 复合函数 y = f(g(x)) |
| --- | --- | --- |
| 增 | 增 | 增 |
| 增 | 减 | 减 |
| 减 | 增 | 减 |
| 减 | 减 | 增 |

使用前必须先求复合函数的定义域，单调区间只能是定义域的子区间。

**最值**：若存在 `x₀ ∈ D`，使对任意 `x ∈ D` 都有 `f(x) ≤ f(x₀)`，则 `f(x₀)` 为最大值。闭区间上的"对勾函数"、二次函数最值要特别注意**顶点是否落在区间内**。

**奇偶性**：

- 前提：定义域关于原点对称（不对称则既非奇也非偶）。
- 奇函数：`f(−x) = −f(x)`，图象关于原点对称。
- 偶函数：`f(−x) = f(x)`，图象关于 y 轴对称。

**常用结论**：

- 若奇函数 f(x) 在 x = 0 处有定义，则 `f(0) = 0`。
- 奇函数在对称的两个区间上单调性**相同**；偶函数在对称的两个区间上单调性**相反**。
- 偶函数满足 `f(−x) = f(x) = f(|x|)`，比较大小时先化到同侧。

### 3.3 幂函数

幂函数：形如 `y = x^α`（α 为常数）的函数。五个常见幂函数：`y = x`，`y = x²`，`y = x³`，`y = x^(1/2) = √x`，`y = x^(−1) = 1/x`。

| 函数 | 定义域 | 值域 | 奇偶性 | 在 (0, +∞) 上 |
| --- | --- | --- | --- | --- |
| y = x | R | R | 奇 | 递增 |
| y = x² | R | [0, +∞) | 偶 | 递增 |
| y = x³ | R | R | 奇 | 递增 |
| y = √x | [0, +∞) | [0, +∞) | 非奇非偶 | 递增 |
| y = 1/x | {x | x ≠ 0} | {y | y ≠ 0} | 奇 | 递减 |

共同点：都经过点 (1, 1)（α ≠ 0 时）；`α > 0` 时在 `(0, +∞)` 上递增，`α < 0` 时在 `(0, +∞)` 上递减。

### 3.4 函数的应用（一）

建立函数模型解决实际问题的步骤：

```
审题（找变量与等量关系）→ 设元 → 建立函数解析式 → 确定定义域（易漏！）
→ 求最值或分析性质 → 回到实际情境作答
```

常用模型：一次函数（匀速变化）、二次函数（面积、利润最值）、分段函数（阶梯计费、出租车计费）。

## 三、典型例题

### 例 1（求定义域）

求函数 `f(x) = √(3 − x) + 1/(x + 2)` 的定义域。

**解析**：需同时满足

- `3 − x ≥ 0`，即 `x ≤ 3`；
- `x + 2 ≠ 0`，即 `x ≠ −2`。

所以定义域为 `{x | x ≤ 3 且 x ≠ −2}`，即 `(−∞, −2) ∪ (−2, 3]`。

### 例 2（判断是否为同一函数）

判断下列各组函数是否为同一函数：

(1) `f(x) = x` 与 `g(x) = x²/x`；  
(2) `f(x) = x` 与 `g(x) = √(x²)`。

**解析**：

(1) **不是**。`g(x)` 的定义域为 `{x | x ≠ 0}`，与 f 的定义域 R 不同。
(2) **不是**。`√(x²) = |x|`，当 `x < 0` 时对应关系与 f 不同。

**方法总结**：判断同一函数"先看定义域，再看对应关系"，两项都相同才是同一个函数。

### 例 3（分离常数法求值域）

求函数 `y = (2x + 1)/(x − 1)` 的值域。

**解析**：分离常数

`y = (2(x − 1) + 3)/(x − 1) = 2 + 3/(x − 1)`

因为 `3/(x − 1) ≠ 0`，所以 `y ≠ 2`。

值域为 `{y | y ≠ 2}`。

**方法总结**：`y = (ax + b)/(cx + d)` 型函数的值域为 `{y | y ≠ a/c}`。

### 例 4（分段函数）

已知 `f(x) = x + 1 (x < 0)`，`f(x) = x² (x ≥ 0)`。求 `f(f(−2))` 与 f(x) 的值域。

**解析**：因为 `−2 < 0`，所以 `f(−2) = −2 + 1 = −1`；又 `−1 < 0`，所以 `f(f(−2)) = f(−1) = −1 + 1 = 0`。

求值域时分段求再取并集：

- 当 `x < 0` 时，`x + 1 < 1`，这部分值域为 `(−∞, 1)`；
- 当 `x ≥ 0` 时，`x² ≥ 0`，这部分值域为 `[0, +∞)`。

取并集得 f(x) 的值域为 R。

### 例 5（定义法证明单调性）

证明函数 `f(x) = x + 1/x` 在 `(1, +∞)` 上单调递增。

**证明**：任取 `x₁, x₂ ∈ (1, +∞)` 且 `x₁ < x₂`，则

`f(x₁) − f(x₂) = (x₁ − x₂) + (1/x₁ − 1/x₂) = (x₁ − x₂) + (x₂ − x₁)/(x₁x₂) = (x₁ − x₂)·(x₁x₂ − 1)/(x₁x₂)`

因为 `1 < x₁ < x₂`，所以 `x₁ − x₂ < 0`，`x₁x₂ > 1` 即 `x₁x₂ − 1 > 0`，`x₁x₂ > 0`。

因此 `f(x₁) − f(x₂) < 0`，即 `f(x₁) < f(x₂)`。

所以 f(x) 在 `(1, +∞)` 上单调递增。

**易错提醒**：第 ③ 步变形是关键，直接作差无法定号时必须通分或分解因式。

### 例 6（复合函数的单调区间）

求函数 `y = √(x² − 2x − 3)` 的单调递增区间。

**解析**：先求定义域：`x² − 2x − 3 ≥ 0`，即 `(x − 3)(x + 1) ≥ 0`，得 `x ≤ −1 或 x ≥ 3`。

令 `u = x² − 2x − 3 = (x − 1)² − 4`，外层 `y = √u` 在 `[0, +∞)` 上单调递增。

- 内层 u 在 `(−∞, −1]` 上递减，由"同增异减"，复合函数在这段上递减；
- 内层 u 在 `[3, +∞)` 上递增，复合函数在这段上递增。

所以单调递增区间为 `[3, +∞)`。

### 例 7（由奇偶性求参数）

已知 `f(x) = x³ + ax² + bx` 是奇函数，求实数 a 的值。

**解析**：由奇函数定义，

`f(−x) = −x³ + ax² − bx = −f(x) = −x³ − ax² − bx`

比较得 `2ax² = 0` 对一切 x 成立，故 `a = 0`。

**方法总结**：由奇偶性求参数，标准做法是写出 `f(−x) = ±f(x)` 后**比较对应项系数**。

### 例 8（奇偶性与单调性综合解不等式）

已知 f(x) 是定义在 R 上的奇函数，且在 `[0, +∞)` 上单调递增，`f(1) = 0`，解不等式 `f(x) > 0`。

**解析**：由奇函数得 `f(0) = 0`。在 `[0, +∞)` 上递增且 `f(1) = 0`：

- 当 `x > 1` 时 `f(x) > f(1) = 0`，符合；
- 当 `0 ≤ x < 1` 时 `f(x) < 0`，不符合。

当 `x < 0` 时，`−x > 0`，由奇性 `f(x) = −f(−x)`：

- 若 `−x > 1`（即 `x < −1`），则 `f(−x) > 0`，故 `f(x) < 0`，不符合；
- 若 `0 < −x < 1`（即 `−1 < x < 0`），则 `f(−x) < 0`，故 `f(x) > 0`，符合。

所以不等式 `f(x) > 0` 的解集为 `{x | −1 < x < 0 或 x > 1}`。

**方法总结**：奇函数 + 单调性解不等式的核心是"化到同一侧"，利用 `f(a) > f(b) ⟺ a > b`（在增函数上）。

### 例 9（幂函数）

已知幂函数 `f(x) = x^(m² − 2m − 3)`（m ∈ Z）在 `(0, +∞)` 上单调递减，且图象关于 y 轴对称，求 m 的值及 f(x) 的解析式。

**解析**：在 `(0, +∞)` 上递减要求指数为负：

`m² − 2m − 3 < 0`，即 `(m − 3)(m + 1) < 0`，得 `−1 < m < 3`。结合 `m ∈ Z` 得 `m = 0, 1, 2`。

图象关于 y 轴对称要求 f(x) 为偶函数，即指数为偶数：

- `m = 0`：指数 −3（奇）；
- `m = 1`：指数 −4（偶），符合；
- `m = 2`：指数 −3（奇）。

所以 `m = 1`，`f(x) = x^(−4) = 1/x⁴`。

### 例 10（函数模型应用）

某工厂生产某种产品的固定成本为 20 000 元，每生产一件产品成本增加 100 元。当产量为 x 件时，销售收入为 `R(x) = 400x − x²/2`（0 ≤ x ≤ 400）。求利润 L(x) 的最大值。

**解析**：利润 = 销售收入 − 总成本，即

`L(x) = (400x − x²/2) − (20000 + 100x) = −x²/2 + 300x − 20000`（0 ≤ x ≤ 400）

这是开口向下的二次函数，对称轴 `x = −300/(2×(−1/2)) = 300`，落在区间内。

`L(300) = −45000 + 90000 − 20000 = 25000`

所以当产量为 300 件时，利润最大，最大利润为 25 000 元。

## 四、易错点清单

1. **忘记求定义域**：求值域、判断单调性、判断奇偶性之前，必须先确定定义域。
2. **用特例判断单调性**：必须对区间内"任意"两个自变量成立，用 `f(1) < f(2)` 不能说明单调递增。
3. **单调区间写成并集**：`(−∞,0) ∪ (0,+∞)` 上 `1/x` 并不单调递减。
4. **忽略定义域对称性**：判断奇偶性第一步是检查定义域是否关于原点对称。
5. **复合函数单调区间超出定义域**：先求定义域，再在定义域内讨论。
6. **求最值不检验顶点位置**：闭区间上二次函数的最值必须讨论对称轴是否落在区间内。
7. **分段函数定义域遗漏**：写解析式时若不写清每段的范围，会变成"多值"的错误表达。
8. **由奇偶性求参数只代特殊值**：代 `x = 1` 只能得到必要条件，务必用"对一切 x 成立"比较系数。

## 五、自测题（限时 45 分钟）

1. 求函数 `f(x) = √(x + 1) + 1/(x − 2)` 的定义域。
2. 判断 `f(x) = x − 1` 与 `g(x) = (x² − 1)/(x + 1)` 是否为同一函数。
3. 求函数 `y = (x + 1)/(x − 2)` 的值域。
4. 已知 `f(x) = x² (x ≤ 0)`，`f(x) = 2x − 1 (x > 0)`，求 `f(f(−1))`。
5. 判断 `f(x) = x³ + x` 的奇偶性。
6. 判断并证明 `f(x) = x² + 1` 在 `(0, +∞)` 上的单调性。
7. 求 `y = x² − 4x + 5` 在 `[0, 3]` 上的最大值与最小值。
8. 已知 f(x) 是偶函数，且在 `(−∞, 0)` 上单调递减，比较 `f(−3)` 与 `f(2)` 的大小。
9. 已知幂函数 `f(x) = x^α` 的图象过点 `(2, 8)`，求 α 及 `f(1/2)`。
10. 已知 f(x) 是定义在 R 上的奇函数，当 `x ≥ 0` 时 `f(x) = x² − 2x`，求当 `x < 0` 时 f(x) 的解析式。

## 六、自测题答案与解析

1. 需 `x + 1 ≥ 0` 且 `x − 2 ≠ 0`，定义域为 `{x | x ≥ −1 且 x ≠ 2}`，即 `[−1, 2) ∪ (2, +∞)`。
2. **不是**。`g(x)` 需 `x + 1 ≠ 0`，即定义域 `{x | x ≠ −1}`，与 f 的定义域 R 不同。
3. 分离常数得 `y = 1 + 3/(x − 2)`，因 `3/(x − 2) ≠ 0`，值域为 `{y | y ≠ 1}`。
4. `−1 ≤ 0`，故 `f(−1) = (−1)² = 1`；`1 > 0`，故 `f(1) = 2 × 1 − 1 = 1`。所以 `f(f(−1)) = 1`。
5. 定义域为 R，关于原点对称。`f(−x) = −x³ − x = −(x³ + x) = −f(x)`，故为**奇函数**。
6. **单调递增**。证明：任取 `0 < x₁ < x₂`，则 `f(x₁) − f(x₂) = x₁² − x₂² = (x₁ + x₂)(x₁ − x₂)`。因 `x₁ + x₂ > 0`，`x₁ − x₂ < 0`，故差为负，即 `f(x₁) < f(x₂)`，所以 f(x) 在 `(0, +∞)` 上单调递增。
7. 配方得 `y = (x − 2)² + 1`，对称轴 `x = 2 ∈ [0, 3]`。最小值 `y(2) = 1`；最大值在距对称轴较远的端点取，`y(0) = 5`，`y(3) = 2`，故最大值为 5。
8. 偶函数满足 `f(−3) = f(3)`。在 `(−∞, 0)` 上递减，由偶函数对称区间单调性相反，得 f(x) 在 `(0, +∞)` 上递增，故 `f(3) > f(2)`，即 `f(−3) > f(2)`。
9. 由 `2^α = 8 = 2³` 得 `α = 3`，故 `f(x) = x³`，`f(1/2) = (1/2)³ = 1/8`。
10. 当 `x < 0` 时 `−x > 0`，代入已知解析式得 `f(−x) = (−x)² − 2(−x) = x² + 2x`。由奇性 `f(x) = −f(−x) = −x² − 2x`。

2. 已知 f(x) 是定义在 `[−2, 2]` 上的偶函数，且在 `[0, 2]` 上单调递增，解不等式 `f(x − 1) < f(1)`。（提示：由偶性得 `f(|x − 1|) < f(1)`，故 `|x − 1| < 1`，结合定义域得 `0 < x < 2`。）
