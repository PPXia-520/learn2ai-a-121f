## 二、知识梳理

### 1.1 集合的概念

- **元素与集合的关系**只有两种：属于 `∈` 或不属于 `∉`。
- **元素的三个特征**：
  - 确定性：给定集合，任一对象是否为它的元素是明确的。反例："高个子同学"不能构成集合。
  - 互异性：集合中元素互不相同，重复写只算一个。
  - 无序性：`{1,2} = {2,1}`。
- **常用数集**：自然数集 `N`（含 0）、正整数集 `N*` 或 `N+`、整数集 `Z`、有理数集 `Q`、实数集 `R`、复数集 `C`。
- **表示方法**：
  - 列举法：元素有限且少时使用，如 `{1, 2, 3}`。
  - 描述法：`{x | 性质}`，竖线前写代表元素，竖线后写满足的条件。注意 `{x | y = x²}` 与 `{y | y = x²}` 是不同的集合。

### 1.2 集合间的基本关系

- 子集：`A ⊆ B` 表示 A 中任意元素都是 B 的元素（"任意"是关键，不要用个别例子判断）。
- 集合相等：`A = B ⟺ A ⊆ B 且 B ⊆ A`。
- 真子集：`A ⊊ B`（也写作 `A ⫋ B`）表示 `A ⊆ B` 且 `A ≠ B`。
- **空集 ∅**：不含任何元素；∅ 是任何集合的子集，是任何非空集合的真子集。
- 计数结论（n 元集合）：子集 `2ⁿ` 个，真子集 `2ⁿ − 1` 个，非空真子集 `2ⁿ − 2` 个。

### 1.3 集合的基本运算

设 U 为全集，A、B 为 U 的子集：

| 运算 | 定义 | 记忆要点 |
| --- | --- | --- |
| 并集 A ∪ B | `{x | x ∈ A 或 x ∈ B}` | "或者"，取两者全部 |
| 交集 A ∩ B | `{x | x ∈ A 且 x ∈ B}` | "并且"，取公共部分 |
| 补集 ∁U A | `{x | x ∈ U 且 x ∉ A}` | 相对于全集而言，换全集则补集变 |

常用等价关系：

- `A ∩ B = A ⟺ A ⊆ B`
- `A ∪ B = B ⟺ A ⊆ B`
- `A ∩ B = ∅` 表示 A、B 无公共元素（注意 A 或 B 可以是 ∅）
- 德摩根律：`∁U(A ∪ B) = (∁U A) ∩ (∁U B)`，`∁U(A ∩ B) = (∁U A) ∪ (∁U B)`

**数轴法**：涉及不等式解集的集合运算，一律画数轴，特别注意**端点是否取到**（实心点与空心点）。

### 1.4 充分条件与必要条件

- 若 `p ⟹ q`，则 p 是 q 的**充分条件**，q 是 p 的**必要条件**。
- 若 `p ⟺ q`，则 p 是 q 的**充要条件**。
- **集合法判断**：设 `A = {x | p(x)}`，`B = {x | q(x)}`，则
  - `A ⊆ B` ⟹ p 是 q 的充分条件（不充分看是否 A ⊊ B）
  - `A ⊇ B` ⟹ p 是 q 的必要条件
  - `A = B` ⟹ p 是 q 的充要条件
- **等价转化法**：`p ⟹ q` 与它的逆否命题 `¬q ⟹ ¬p` 同真同假，命题难判断时可转化为逆否命题。

### 1.5 全称量词与存在量词

- 全称量词命题：`∀x ∈ M, p(x)`，读作"对 M 中任意 x，p(x) 成立"；举出一个反例即可否定。
- 存在量词命题：`∃x ∈ M, p(x)`，读作"存在 M 中的 x 使 p(x) 成立"；找出一个例子即可肯定。
- **含量词命题的否定**（"改量词、否结论"）：

| 原命题 | 否定 |
| --- | --- |
| `∀x ∈ M, p(x)` | `∃x ∈ M, ¬p(x)` |
| `∃x ∈ M, p(x)` | `∀x ∈ M, ¬p(x)` |

注意：全称量词命题的否定只否定结论，不改条件。

## 三、典型例题

### 例 1（元素的互异性 · 分类讨论）

已知集合 `A = {a + 2, (a + 1)², a² + 3a + 3}`，且 `1 ∈ A`，求实数 a 的值。

**解析**：1 可能等于三者中的任一元素，逐一讨论并检验互异性。

- 若 `a + 2 = 1`，则 `a = −1`，此时 `A = {1, 0, 1}`，元素重复，不符合互异性，舍去。
- 若 `(a + 1)² = 1`，则 `a = 0` 或 `a = −2`。
  - `a = 0`：`A = {2, 1, 3}`，三个元素互异，符合要求。
  - `a = −2`：`A = {0, 1, 1}`，重复，舍去。
- 若 `a² + 3a + 3 = 1`，即 `a² + 3a + 2 = 0`，解得 `a = −1` 或 `a = −2`，均已在上面被否。

综上，`a = 0`。

**方法总结**：含参集合问题必须有"检验互异性"这一步，这是最容易丢分的地方。

### 例 2（由包含关系求参数 · 端点临界值）

已知 `A = {x | −1 ≤ x ≤ 3}`，`B = {x | x < a}`，若 `A ⊆ B`，求 a 的取值范围。

**解析**：`A ⊆ B` 要求 A 中每个元素都满足 `x < a`。A 的最大元素是 3，故必须 `a > 3`。

检验端点：若 `a = 3`，则 `3 ∉ B`，但 `3 ∈ A`，不满足 `A ⊆ B`。

所以 `a > 3`。

**方法总结**：由包含关系求参数范围时，**端点必须单独验证**——把临界值代回原集合看是否符合。

### 例 3（含参子集 · 元素枚举法）

已知 `A = {x | x² − 3x + 2 = 0}`，`B = {x | x² − ax + a − 1 = 0}`，若 `B ⊆ A`，求 a 的值。

**解析**：`A = {1, 2}`。对 B 中的方程分解因式：

`x² − ax + a − 1 = (x − 1)(x − (a − 1))`

所以 `B = {1, a − 1}`（当 `a − 1 = 1` 时 `B = {1}`）。

由 `B ⊆ A` 得 `a − 1 ∈ {1, 2}`：

- `a − 1 = 1`，即 `a = 2`，此时 `B = {1} ⊆ A`，符合；
- `a − 1 = 2`，即 `a = 3`，此时 `B = {1, 2} = A`，符合。

所以 `a = 2` 或 `a = 3`。

### 例 4（集合运算 · 数轴法）

设全集 `U = R`，`A = {x | x² − 4x + 3 < 0}`，`B = {x | x ≥ 2}`，求 `A ∩ B` 与 `A ∪ (∁U B)`。

**解析**：`x² − 4x + 3 < 0 ⟺ (x − 1)(x − 3) < 0 ⟺ 1 < x < 3`，即 `A = {x | 1 < x < 3}`。

- `A ∩ B = {x | 2 ≤ x < 3}`。
- `∁U B = {x | x < 2}`，在数轴上与 A 取并集得 `A ∪ (∁U B) = {x | x < 3}`。

**方法总结**：先解不等式把集合化成"最简区间形式"，再画数轴取交并补。

### 例 5（充分必要条件的判断 · 集合法）

判断 `x > 2` 是 `x² > 4` 的什么条件。

**解析**：记 `A = {x | x > 2}`，`B = {x | x² > 4} = {x | x > 2 或 x < −2}`。

`A ⊊ B`，故 `x > 2` 能推出 `x² > 4`（充分），但 `x² > 4` 不能推出 `x > 2`（如 `x = −3` 时 `x² = 9 > 4` 却不满足 `x > 2`）。

所以是**充分不必要条件**。

### 例 6（由充分不必要条件求参数）

已知 `p: −2 ≤ x ≤ 10`，`q: 1 − m ≤ x ≤ 1 + m (m > 0)`。若 p 是 q 的充分不必要条件，求 m 的取值范围。

**解析**：p 是 q 的充分不必要条件 ⟺ `P ⊊ Q`，其中 `P = [−2, 10]`，`Q = [1 − m, 1 + m]`。

需要 `1 − m ≤ −2` 且 `10 ≤ 1 + m`，即 `m ≥ 3` 且 `m ≥ 9`，故 `m ≥ 9`。

检验：当 `m = 9` 时 `Q = [−8, 10] ⊋ P`，满足严格包含；当 `m > 9` 时更成立。

所以 `m ≥ 9`。

**方法总结**：把条件翻译成集合的包含关系后，问题从"逻辑判断"变成"端点比较"。

### 例 7（含量词命题的否定与真假判断）

写出命题 `∀x ∈ R, x² + 2x + 3 > 0` 的否定，并判断原命题的真假。

**解析**：否定为 `∃x ∈ R, x² + 2x + 3 ≤ 0`。

因为 `x² + 2x + 3 = (x + 1)² + 2 ≥ 2 > 0` 对一切实数成立，所以原命题为**真**，其否定为**假**。

### 例 8（存在量词命题与参数范围）

若命题 `∃x ∈ R, x² + 2x + a = 0` 为真，求 a 的取值范围。

**解析**：方程有实数解 ⟺ 判别式 `Δ = 4 − 4a ≥ 0`，得 `a ≤ 1`。

也可从值域角度：`x² + 2x = (x + 1)² − 1 ≥ −1`，故 `a = −(x² + 2x) ≤ 1`。

所以 `a ≤ 1`。

### 例 9（集合的新定义 · 化简后验证）

设 `S = {x | x = m + √2 n, m ∈ Z, n ∈ Z}`，判断 `1 / (3 − 2√2)` 是否属于 S。

**解析**：分母有理化：

`1 / (3 − 2√2) = (3 + 2√2) / (3² − (2√2)²) = (3 + 2√2) / (9 − 8) = 3 + 2√2`

取 `m = 3`，`n = 2`，均属于 Z，故 `3 + 2√2 ∈ S`，即 `1 / (3 − 2√2) ∈ S`。

**方法总结**：判断元素是否属于描述法给出的集合，就是把对象整理成描述的形式。

## 四、易错点清单

1. **忘记检验互异性**：含参集合求出参数后，必须代回检验是否有重复元素。
2. **混淆"∈"与"⊆"**：元素与集合之间用 `∈`，集合与集合之间用 `⊆`；`{1} ∈ {{1}}` 对，`1 ⊆ {1}` 错。
3. **忽略空集**：由 `A ⊆ B` 求参数时，若 A 可含参数，必须先讨论 `A = ∅`（例 9 中的自测题就是此类）。
4. **端点丢分**：数轴法取交并时，端点是实心还是空心要写清楚；由包含关系求范围时，端点值要单独验证。
5. **补集换个全集就变**：`∁U A` 依赖 U，审题先找"全集是谁"。
6. **否定命题时改错对象**：`∀x, p(x)` 的否定是 `∃x, ¬p(x)`，只改量词与结论，**不改条件**。
7. **把"充分"与"必要"说反**：记口诀"小范围推大范围"，即范围小的条件是范围大的条件的充分条件（例 5、例 6）。

## 五、自测题（限时 40 分钟）

1. 设 `A = {1, 2, 3}`，`B = {2, 3, 4}`，求 `A ∪ B`、`A ∩ B`，并写出 `A ∩ B` 的所有子集个数。
2. 用列举法表示集合 `A = {x ∈ N | 1 ≤ x < 4}`。
3. 已知集合 `M = {x | x² + x − 6 = 0}`，写出 M 的所有元素。
4. 已知 `A = {x | −1 < x < 2}`，`B = {x | x ≤ 1}`，求 `A ∩ B`。
5. 已知 `A = {x | x < a}`，`B = {x | x < 2}`，若 `A ⊆ B`，求 a 的取值范围。
6. "a = 1" 是 "a² = 1" 的什么条件？
7. "x > 0" 是 "x ≠ 0" 的什么条件？
8. 写出命题 `∃x ∈ R, x² − x + 1 < 0` 的否定，并判断原命题与否定命题的真假。
9. 已知 `A = {x | 2a ≤ x ≤ a + 3}`，`B = {x | x < −1 或 x > 5}`，若 `A ∩ B = ∅`，求 a 的取值范围。
10. 设 `U = {1, 2, 3, 4, 5}`，`A = {1, 3, 5}`，`B = {2, 4, 5}`，求 `∁U(A ∪ B)` 与 `∁U(A ∩ B)`。

## 六、自测题答案与解析

1. `A ∪ B = {1, 2, 3, 4}`，`A ∩ B = {2, 3}`；`A ∩ B` 有 2 个元素，子集个数为 `2² = 4` 个。
2. 满足条件的自然数只有 1、2、3，故 `A = {1, 2, 3}`。
3. `x² + x − 6 = 0 ⟺ (x + 3)(x − 2) = 0`，故 `M = {−3, 2}`。
4. 画数轴，公共部分为 `{x | −1 < x ≤ 1}`。
5. 需 A 中所有元素都小于 2，故 `a ≤ 2`。检验：`a = 2` 时 `A = B`，满足 `A ⊆ B`，故端点可取。
6. `a = 1 ⟹ a² = 1` 成立；`a² = 1 ⟹ a = ±1`，不一定 `a = 1`。故是**充分不必要条件**。
7. `x > 0 ⟹ x ≠ 0` 成立；`x ≠ 0` 时 x 可正可负，推不出 `x > 0`。故是**充分不必要条件**。
8. 否定：`∀x ∈ R, x² − x + 1 ≥ 0`。因为 `x² − x + 1 = (x − 1/2)² + 3/4 > 0` 恒成立，所以**否定命题为真，原命题为假**。
9. 分两种情况：
   - `A = ∅`：`2a > a + 3`，即 `a > 3`，此时 `A ∩ B = ∅` 成立。
   - `A ≠ ∅`：需 `A ⊆ {x | −1 ≤ x ≤ 5}`，即 `2a ≥ −1` 且 `a + 3 ≤ 5`，且 `2a ≤ a + 3`，解得 `−1/2 ≤ a ≤ 2`。

   综上 `a ∈ [−1/2, 2] ∪ (3, +∞)`。
10. `A ∪ B = {1, 2, 3, 4, 5} = U`，故 `∁U(A ∪ B) = ∅`；`A ∩ B = {5}`，故 `∁U(A ∩ B) = {1, 2, 3, 4}`。

## 七、思考与拓展

1. 已知集合 A 满足 `{1, 2} ⊆ A ⊆ {1, 2, 3, 4, 5}`，这样的 A 共有多少个？（提示：只需决定 3、4、5 是否入选，答案 2³ = 8 个。）
2. 若 "`∀x ∈ [1, 2], x² − a ≤ 0`" 为真命题，求 a 的取值范围。（提示：转化为 a ≥ (x²) 的最大值，答案 a ≥ 4。）
3. 判断并证明：`A ∩ B = A ∪ B` 的充要条件是 `A = B`。（提示：由 `A ⊆ A ∪ B = A ∩ B ⊆ B` 及同理反向得证。）
