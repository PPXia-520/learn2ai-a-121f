## 三、使用建议

**学生**：

1. 学期初先读 `00-课程大纲/高中数学课程大纲.md`，了解整个高中的学习地图。
2. 每周日晚读 `00-课程大纲/高一上教学进度表.md`，提前预习下周内容。
3. 上课前读讲义的"知识结构"与"知识梳理"；课后做"典型例题"；单元测前完成"自测题"。
4. 每次作业或测评后用 `05-模板/错题本与学习记录模板.md` 做归因分析。
5. 自己的成果一律写入 `work/<你的用户UUID>/<作业ID>/`，不要写进 `materials/` 或 `assignments/`。

**老师**：

1. 按 `00-课程大纲/高一上教学进度表.md` 推进，难点周（第 5、6、13、17 周）在辅导课加练。
2. 出题使用 `templates/assignment.md` 格式，登记到 `assignments/<作业ID>/assignment.md` 后再发布。
3. 阶段测评可直接使用 `04-测评/` 中的试卷，按班级水平增删题目。
4. 反馈通过课程服务的 `feedback get` / `feedback save` 保存，不提交到 Git。
