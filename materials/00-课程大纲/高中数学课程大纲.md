# 高中数学课程大纲（三年一贯制）

> 适用班级：数学课 A 班  
> 编写依据：《普通高中数学课程标准（2017 年版 2020 年修订）》、人教 A 版（2019）高中数学教材、新高考数学命题要求  
> 课时基准：每周 5 课时正课 + 1 课时答疑辅导，每学期约 20 周

## 一、课程定位与目标

### 1.1 课程定位

本课程面向高中数学 A 班，采用"主干模块 + 分层任务"的组织方式：以教材章节为主线保证体系完整，以高考七大主干（函数与导数、三角、数列、立体几何、解析几何、概率统计、向量与复数）为线索保证复习时不重复、不遗漏。

### 1.2 六大核心素养目标

| 素养 | 本课程的具体落点 |
| --- | --- |
| 数学抽象 | 从具体情境中抽象出集合、函数、向量、概率等数学模型 |
| 逻辑推理 | 定义 → 性质 → 判定的推理链条；充分必要条件的辨析；证明书写规范 |
| 数学建模 | 用函数、三角函数、数列、统计模型刻画实际问题的增长、周期、随机性 |
| 直观想象 | 函数图象、立体图形的空间想象、解析几何中"数形互译" |
| 数学运算 | 指数对数运算、三角恒等变换、向量与坐标运算、导数运算的准确性与算理 |
| 数据分析 | 统计图表、样本估计总体、回归与独立性检验的解读与批判 |

### 1.3 学期结束时学生应达到的水平

1. 能独立复述每一章的知识结构图，并说清知识点之间的从属关系。
2. 能在 40 分钟内完成一道高考中档综合题，书写完整、步骤规范。
3. 具备"读题 → 翻译成数学模型 → 求解 → 回代检验"的完整解题闭环。
4. 形成个人错题档案，能做归因分析（概念不清 / 方法不会 / 运算失误 / 审题偏差）。

### 2.1 各阶段能力目标

- 第一阶段（函数思想奠基）：完成从"算式运算"到"变量关系"的思维跃迁，把函数作为研究一切变化规律的统一工具。
- 第二阶段（几何与随机启蒙）：建立空间观念与随机观念，掌握向量作为"数与形之间桥梁"的双重身份。
- 第三阶段（解析几何成型）：掌握"用代数方法研究几何对象"的一般范式，熟练处理直线、圆、圆锥曲线的位置关系。
- 第四阶段（数列与导数）：掌握离散型递推问题的通项与求和套路，掌握用导数研究函数单调性、极值、最值的完整流程。
- 第五阶段（计数与统计推断）：从"算概率"走向"建分布、做推断"，形成对数据的批判性解读能力。

## 四、教学主线与处理策略

### 4.1 三条贯穿全课的主线

1. **函数主线**：概念（三要素、表示）→ 性质（单调性、奇偶性、最值）→ 具体模型（幂、指数、对数、三角）→ 应用（零点、建模）。每引入一种新函数，都用同一套问题清单去研究：定义域？值域？单调性？奇偶性？图象特征？特殊点？
2. **数形结合主线**：从数轴、函数图象，到向量、坐标系、解析几何，始终训练"由式想形、由形定式"的双向翻译能力。
3. **推理与书写主线**：从第 1 章的逻辑用语开始，要求所有证明使用"因为……所以……"的规范结构，禁止跳步和"显然"。

### 4.2 分层任务设计

| 层次 | 面向 | 任务要求 |
| --- | --- | --- |
| A 层（基础） | 全体 | 教材例题与课后习题 A 组，掌握定义与基本运算 |
| B 层（核心） | 全体 | 讲义"典型例题"与自测题，达到高考中档题水平 |
| C 层（拓展） | 学有余力 | 讲义"思考与拓展"，涉及参数讨论、抽象函数、构造法 |

### 4.3 课堂结构模板（每课时）

1. 前测 5 分钟：回顾上节核心结论（1—2 题）。
2. 概念建构 15 分钟：从情境或问题出发抽象出定义。
3. 例题精讲 15 分钟：一题一法，讲清算理与书写。
4. 当堂练习 8 分钟：同桌互批。
5. 小结与作业 2 分钟：明确本节知识在结构图中的位置。
