# 高中数学核心公式与结论速查

## 一、集合与常用逻辑用语

| 项目 | 内容 |
| --- | --- |
| 元素三性 | 确定性、互异性、无序性 |
| 子集个数 | n 元集合的子集有 2ⁿ 个，真子集 2ⁿ − 1 个，非空真子集 2ⁿ − 2 个 |
| 并集 | A ∪ B = {x \| x ∈ A 或 x ∈ B} |
| 交集 | A ∩ B = {x \| x ∈ A 且 x ∈ B} |
| 补集 | ∁U A = {x \| x ∈ U 且 x ∉ A} |
| 集合与包含 | A ∩ B = A ⟺ A ⊆ B；A ∪ B = B ⟺ A ⊆ B |
| 德摩根律 ▲ | ∁U(A ∪ B) = (∁U A) ∩ (∁U B)；∁U(A ∩ B) = (∁U A) ∪ (∁U B) |
| 充分必要 | p ⟹ q：p 充分，q 必要；小范围推大范围 |
| 含量词命题的否定 ▲ | ¬(∀x, p(x)) = ∃x, ¬p(x)；¬(∃x, p(x)) = ∀x, ¬p(x) |

## 二、不等式

| 项目 | 内容 |
| --- | --- |
| 作差比较 | a − b > 0 ⟺ a > b |
| 可乘性 | a > b，c > 0 ⟹ ac > bc；a > b，c < 0 ⟹ ac < bc |
| 同向同正可乘 | a > b > 0，c > d > 0 ⟹ ac > bd |
| 基本不等式 ▲ | a > 0，b > 0 时 √(ab) ≤ (a + b)/2，当且仅当 a = b 取等 |
| 常用变形 | a + b ≥ 2√(ab)；ab ≤ ((a + b)/2)² |
| 对勾函数 | y = x + a/x（a > 0）在 (0, √a] 递减、[√a, +∞) 递增，最小值 2√a |
| 一元二次不等式（a > 0） | Δ > 0：解集在两根之外或之间；Δ = 0 与 Δ < 0 按表讨论 |
| 韦达定理 | x₁ + x₂ = −b/a，x₁x₂ = c/a |
| 分式不等式 | f/g ≥ 0 ⟺ f·g ≥ 0 且 g ≠ 0 |
| 恒成立（∀x ∈ R） | ax² + bx + c > 0 ⟺ a > 0 且 Δ < 0 |

## 三、函数的概念与性质

| 项目 | 内容 |
| --- | --- |
| 函数三要素 | 定义域、对应关系、值域（值域由前两者确定） |
| 定义域限制 | 分母 ≠ 0；偶次根号下 ≥ 0；零次幂底数 ≠ 0；对数真数 > 0 |
| 单调性定义 | ∀x₁ < x₂ ∈ D，f(x₁) < f(x₂) ⟹ 在 D 上递增 |
| 证明单调性五步 | 取值 → 作差 → 变形 → 定号 → 结论 |
| 复合函数单调性 | 同增异减（先求定义域） |
| 奇偶性前提 | 定义域关于原点对称 |
| 奇函数 | f(−x) = −f(x)，图象关于原点对称；若 0 在定义域内则 f(0) = 0 |
| 偶函数 | f(−x) = f(x)，图象关于 y 轴对称；f(x) = f(\|x\|) |
| 对称区间单调性 ▲ | 奇函数相同，偶函数相反 |
| 分离常数 | (ax + b)/(cx + d) = a/c + (b − ad/c)/(cx + d)，值域为 {y \| y ≠ a/c} |

## 四、指数与对数

| 项目 | 内容 |
| --- | --- |
| 分数指数幂 | a^(m/n) = ⁿ√(a^m)（a > 0）；a^(−m/n) = 1/a^(m/n) |
| 根式性质 | ⁿ√(aⁿ) = a（n 奇）；= \|a\|（n 偶） |
| 指数运算法则 | a^r·a^s = a^(r+s)；(a^r)^s = a^(rs)；(ab)^r = a^r·b^r |
| 对数定义 | a^x = N ⟺ x = log_a N（a > 0，a ≠ 1，N > 0） |
| 对数恒等式 | a^(log_a N) = N；log_a 1 = 0；log_a a = 1 |
| 对数运算律 | log_a(MN) = log_a M + log_a N；log_a(M/N) = log_a M − log_a N；log_a M^n = n·log_a M |
| 换底公式 ▲ | log_a b = log_c b / log_c a；log_a b · log_b a = 1 |
| 指数函数 y = a^x | 定义域 R，值域 (0, +∞)，过 (0, 1)，a > 1 增、0 < a < 1 减 |
| 对数函数 y = log_a x | 定义域 (0, +∞)，值域 R，过 (1, 0)，a > 1 增、0 < a < 1 减 |
| 反函数 | y = a^x 与 y = log_a x 图象关于 y = x 对称 |
| 零点存在定理 | f(x) 在 [a, b] 上连续且 f(a)·f(b) < 0 ⟹ 存在 c ∈ (a, b) 使 f(c) = 0 |
| 增长快慢 | x → +∞ 时 log_a x ≪ x^n ≪ a^x（a > 1，n > 0） |

## 五、三角函数

| 项目 | 内容 |
| --- | --- |
| 角度弧度互化 | 180° = π rad；1 rad = (180/π)° ≈ 57.30° |
| 终边相同的角 | {β \| β = α + k·360°, k ∈ Z} |
| 弧长与扇形面积 | l = \|α\|r；S = ½lr = ½\|α\|r² |
| 定义 | sinα = y/r，cosα = x/r，tanα = y/x（r = √(x²+y²)） |
| 符号规律 | 一全正，二正弦，三正切，四余弦 |
| 平方关系 ▲ | sin²α + cos²α = 1 |
| 商数关系 | tanα = sinα/cosα |
| 诱导公式口诀 | 奇变偶不变，符号看象限 |
| 两角和差 ▲ | sin(α±β) = sinαcosβ ± cosαsinβ；cos(α±β) = cosαcosβ ∓ sinαsinβ |
| 正切和差 | tan(α±β) = (tanα ± tanβ)/(1 ∓ tanαtanβ) |
| 二倍角 ▲ | sin2α = 2sinαcosα；cos2α = cos²α − sin²α = 2cos²α − 1 = 1 − 2sin²α |
| 降幂公式 | sin²α = (1 − cos2α)/2；cos²α = (1 + cos2α)/2 |
| 辅助角公式 ▲ | a·sinx + b·cosx = √(a²+b²)·sin(x+φ)，tanφ = b/a |
| 周期公式 | y = Asin(ωx+φ) 的最小正周期 T = 2π/\|ω\| |
| 对称轴（正弦型） | ωx + φ = π/2 + kπ |
| 对称中心（正弦型） | ωx + φ = kπ |

## 六、平面向量（第二阶段）

| 项目 | 内容 |
| --- | --- |
| 共线定理 | a ∥ b（b ≠ 0）⟺ 存在唯一 λ 使 a = λb |
| 坐标运算 | a = (x₁, y₁)，b = (x₂, y₂)：a ± b = (x₁ ± x₂, y₁ ± y₂) |
| 数量积 | a·b = \|a\|\|b\|cosθ = x₁x₂ + y₁y₂ |
| 垂直判定 | a ⊥ b ⟺ a·b = 0 ⟺ x₁x₂ + y₁y₂ = 0 |

| 夹角 | cosθ = (a·b)/(\|a\|\|b\|) |

| 正弦定理 | a/sinA = b/sinB = c/sinC = 2R |
| 余弦定理 | a² = b² + c² − 2bc·cosA |

## 八、一元函数的导数（第四阶段）

| 项目 | 内容 |
| --- | --- |
| 导数定义 | f'(x₀) = lim(Δx→0) [f(x₀+Δx) − f(x₀)]/Δx |
| 常用导数 | (xⁿ)' = nx^(n−1)；(sinx)' = cosx；(cosx)' = −sinx；(eˣ)' = eˣ；(lnx)' = 1/x |
| 运算法则 | (uv)' = u'v + uv'；(u/v)' = (u'v − uv')/v² |
| 单调性 ▲ | f'(x) > 0 ⟹ 递增；f'(x) < 0 ⟹ 递减 |
| 极值 | f'(x₀) = 0 且 f'(x) 在 x₀ 两侧变号 |
| 最值 | 闭区间上比较极值点与端点的函数值 |
| 切线方程 | y − f(x₀) = f'(x₀)(x − x₀) |

## 九、立体几何与解析几何常用结论（第三阶段）

| 项目 | 内容 |
| --- | --- |
| 线面平行判定 | 平面外一条直线与平面内一条直线平行 ⟹ 线面平行 |
| 面面平行判定 | 一个平面内两条相交直线分别平行于另一个平面 ⟹ 面面平行 |
| 线面垂直判定 | 一条直线与平面内两条相交直线都垂直 ⟹ 线面垂直 |
| 距离公式 | \|AB\| = √((x₁−x₂)² + (y₁−y₂)²) |
| 点到直线距离 | d = \|Ax₀ + By₀ + C\|/√(A² + B²) |
| 斜率 | k = (y₂−y₁)/(x₂−x₁) = tanα（α ≠ 90°） |
| 两直线平行/垂直 | k₁ = k₂ / k₁k₂ = −1（斜率都存在时） |
| 圆的方程 | (x − a)² + (y − b)² = r²；x² + y² + Dx + Ey + F = 0（D²+E²−4F > 0） |
| 椭圆 | x²/a² + y²/b² = 1（a > b > 0），c² = a² − b²，离心率 e = c/a ∈ (0, 1) |
| 双曲线 | x²/a² − y²/b² = 1，c² = a² + b²，渐近线 y = ±(b/a)x，e > 1 |
| 抛物线 | y² = 2px（p > 0），焦点 (p/2, 0)，准线 x = −p/2，e = 1 |

## 十、概率与统计（第二、五阶段）

| 项目 | 内容 |

| 组合数 | C(n, m) = n!/[m!(n−m)!]；C(n, m) = C(n, n−m) |
| 二项式定理 | (a + b)ⁿ = Σ C(n, k)a^(n−k)b^k |
| 线性回归 | 回归直线过样本中心点 (x̄, ȳ) |
