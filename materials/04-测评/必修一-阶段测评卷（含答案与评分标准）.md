## 参考答案与评分标准

### 一、单项选择题（每小题 5 分，共 40 分）

| 题号 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 答案 | A | B | A | B | A | B | B | A |

**简析**

1. 在数轴上取公共部分：{x | 1 ≤ x ≤ 2}，选 A。
2. 全称量词命题的否定：改量词、否结论，得 "∃x ∈ R，x² − x + 1 ≤ 0"，选 B。
3. x > 1 ⟹ x² > 1；反之取 x = −2 不成立，故是充分不必要条件，选 A。
4. 需 2 − x ≥ 0 且 x + 1 ≠ 0，即 x ≤ 2 且 x ≠ −1，故选 B。
5. a ∈ (1, 2)，b = 0.09 ∈ (0, 1)，c < 0，故 a > b > c，选 A。
6. f(1) = 1 − 2 = −1，f(−1) = −f(1) = 1，选 B。
7. T = 2π/2 = π，选 B。
8. 平方得 1 + sin2α = 1/9，故 sin2α = −8/9，选 A。

### 二、多项选择题（每小题 5 分，共 20 分）

| 题号 | 9 | 10 | 11 | 12 |
| --- | --- | --- | --- | --- |
| 答案 | AC | ABC | ABC | AC |

**简析**

9. y = −1/x 在 (0, +∞) 上递增（A 对）；y = x² − 2x 在 (0, 1) 上递减（B 错）；y = √x 递增（C 对）；y = log₁/₂x 递减（D 错）。
10. T = 2π/2 = π（A 对）；最大值 2（B 对）；当 x = π/3 时 2x − π/6 = π/2，取到最大值，故 x = π/3 是对称轴（C 对）；在 [0, π/6] 上 2x − π/6 ∈ [−π/6, π/6]，函数递增（D 错）。
11. A = {1, 2}。a = 0 时 B = ∅ ⊆ A；a ≠ 0 时 B = {1/a}，需 1/a ∈ {1, 2}，即 a = 1 或 a = 1/2。故选 ABC。
12. A 由可加性成立；B 当 c = 0 时不成立；C 由同为正数时的倒数性质成立；D 取 a = −2，b = 1 不成立。故选 AC。

### 三、填空题（每小题 5 分，共 20 分）

13. **4**。`(1/4)^(−1/2) = 4^(1/2) = 2`，`log₃9 = 2`，故原式 = 4。
14. **4/3**。`(sinα + cosα)/sinα = 1 + cosα/sinα = 1 + 1/tanα = 1 + 1/3 = 4/3`。
15. **1**。`f(1) = 2 + 1 − 5 = −2 < 0`，`f(2) = 4 + 2 − 5 = 1 > 0`，且 f(x) 单调递增，故零点在 (1, 2) 内，n = 1。
16. **π/6**。由最大值 2 得 A = 2；由 T = π 得 ω = 2；由过点 (0, 1) 得 `2sinφ = 1`，即 `sinφ = 1/2`，结合 `|φ| < π/2` 得 φ = π/6。

### 四、解答题（共 70 分）

#### 17.（10 分）

**(1)（4 分）** 当 a = 1 时，`B = {x | 2 ≤ x ≤ 5}`。（1 分）

在数轴上求交集：`A ∩ B = {x | 3 ≤ x ≤ 5}`。（3 分，画出数轴或说明端点均可）

**(2)（6 分）** `A ∪ B = R` 等价于 B 包含 A 的补集 `∁R A = {x | −1 < x < 3}`。（2 分）

因此需 `2a ≤ −1` 且 `a + 4 ≥ 3`。（2 分）

解得 `a ≤ −1/2` 且 `a ≥ −1`，即 `−1 ≤ a ≤ −1/2`。（1 分）

检验：此时 `2a ≤ −1 < 3 ≤ a + 4`，B 非空且覆盖 `(−1, 3)`，满足要求。（1 分）

> 评分提醒：只写"a ≤ −1/2"或只写"a ≥ −1"的得 2 分；未检验 B 非空不扣分，但漏解要扣分。

#### 18.（12 分）

**(1)（6 分）** 任取 `1 ≤ x₁ < x₂ ≤ 2`。（1 分）

`f(x₁) − f(x₂) = (x₁ + 4/x₁) − (x₂ + 4/x₂) = (x₁ − x₂) + 4(x₂ − x₁)/(x₁x₂) = (x₁ − x₂)·(x₁x₂ − 4)/(x₁x₂)`。（3 分）

因为 `x₁ − x₂ < 0`，`1 ≤ x₁x₂ < 4` 即 `x₁x₂ − 4 < 0`，`x₁x₂ > 0`，所以 `f(x₁) − f(x₂) > 0`，即 `f(x₁) > f(x₂)`。（1 分）

所以 f(x) 在 [1, 2] 上单调递减。（1 分）

**(2)（6 分）** 由 (1) 知 f(x) 在 [1, 2] 上递减，故在 [1, 2] 上 `f(2) = 4 ≤ f(x) ≤ f(1) = 5`。（2 分）

当 `x ≥ 2` 时，由基本不等式（或与 (1) 类似地证明单调性）知 f(x) 在 [2, 5] 上递增，故在 [2, 5] 上 `f(2) = 4 ≤ f(x) ≤ f(5) = 5 + 4/5 = 29/5`。（3 分）

综上，f(x) 在 [1, 5] 上的最小值为 `4`（当 x = 2 时取得），最大值为 `29/5`（当 x = 5 时取得）。（1 分）

> 评分提醒：第 (2) 问若只用基本不等式得最小值 4 而最大值的说明不完整，扣 2 分。

#### 19.（12 分）

**(1)（6 分）** 最小正周期 `T = 2π/2 = π`。（2 分）

令 `−π/2 + 2kπ ≤ 2x + π/6 ≤ π/2 + 2kπ`，（2 分）

解得 `−π/3 + kπ ≤ x ≤ π/6 + kπ`。

所以单调递增区间为 `[−π/3 + kπ, π/6 + kπ]`（k ∈ Z）。（2 分）

**(2)（6 分）** 当 `x ∈ [0, π/2]` 时，`2x + π/6 ∈ [π/6, 7π/6]`。（2 分）

在此区间上 `sin` 的最大值为 1（当 2x + π/6 = π/2，即 x = π/6 时取得），最小值为 `sin(7π/6) = −1/2`（当 x = π/2 时取得）。（3 分）

所以 `f(x)` 的最大值为 2，最小值为 −1。（1 分）

> 评分提醒：若只代端点 x = 0、x = π/2 求最值而忽略极值点 x = π/6，本问扣 3 分。

#### 20.（12 分）

**(1)（3 分）** 需 `1 + x > 0` 且 `1 − x > 0`，即 `−1 < x < 1`。

所以定义域为 `(−1, 1)`。（3 分）

**(2)（4 分）** 定义域 `(−1, 1)` 关于原点对称。（1 分）

`f(−x) = log₂(1 − x) − log₂(1 + x) = −[log₂(1 + x) − log₂(1 − x)] = −f(x)`。（2 分）

所以 f(x) 是奇函数。（1 分）

**(3)（5 分）** 由运算律，`f(x) = log₂[(1 + x)/(1 − x)]`。（1 分）

不等式化为 `log₂[(1 + x)/(1 − x)] > log₂2`，因底数 2 > 1，函数递增，故

`(1 + x)/(1 − x) > 2`。（2 分）

由定义域知 `1 − x > 0`，两边同乘 `1 − x` 得 `1 + x > 2 − 2x`，即 `x > 1/3`。（1 分）

结合 `−1 < x < 1`，不等式的解集为 `{x | 1/3 < x < 1}`。（1 分）

> 评分提醒：未说明"底数 2 > 1 故不等号方向不变"扣 1 分；未与定义域取交集扣 2 分。

#### 21.（12 分）

**(1)（4 分）** 当 a = 1 时，`f(x) = x² − 2x + 2 = (x − 1)² + 1`。（1 分）

对称轴 x = 1 落在 [−1, 1] 的右端点，故最小值为 `f(1) = 1`，最大值为 `f(−1) = 1 + 2 + 2 = 5`。（2 分）

所以 f(x) 在 [−1, 1] 上的值域为 `[1, 5]`。（1 分）

**(2)（8 分）** `f(x) = (x − a)² + 2 − a²`，对称轴 `x = a`。（2 分）

分类讨论：

- 当 `a < −1` 时，f(x) 在 [−1, 1] 上单调递增，`g(a) = f(−1) = 1 + 2a + 2 = 2a + 3`；（2 分）
- 当 `−1 ≤ a ≤ 1` 时，最小值在顶点处取得，`g(a) = f(a) = 2 − a²`；（2 分）
- 当 `a > 1` 时，f(x) 在 [−1, 1] 上单调递减，`g(a) = f(1) = 1 − 2a + 2 = 3 − 2a`。（2 分）

所以

```
g(a) = 2a + 3   (a < −1)
g(a) = 2 − a²   (−1 ≤ a ≤ 1)
g(a) = 3 − 2a   (a > 1)
```

> 评分提醒：分类讨论的三种情况每漏一种扣 2 分；端点归入哪一段均可，但必须不重不漏。

#### 22.（12 分）

**解**：设售价在 40 元/件的基础上上涨 x 元（`x ≥ 0`），则

- 每件利润为 `(40 + x) − 30 = 10 + x` 元；
- 月销售量为 `500 − 20x` 件。（3 分）

设月利润为 L(x) 元，则

`L(x) = (10 + x)(500 − 20x) = −20x² + 300x + 5000`，（3 分）

其中由 `500 − 20x ≥ 0` 得定义域 `0 ≤ x ≤ 25`。（2 分）

这是开口向下的二次函数，对称轴 `x = −300/(2 × (−20)) = 7.5`，落在区间内。（2 分）

`L(7.5) = −20 × 56.25 + 300 × 7.5 + 5000 = −1125 + 2250 + 5000 = 6125`。

所以当售价定为 `40 + 7.5 = 47.5` 元/件时，月利润最大，最大月利润为 6125 元。（2 分）

> 评分提醒：未写定义域 `0 ≤ x ≤ 25` 扣 2 分；未说明对称轴落在定义域内直接代入扣 1 分。
