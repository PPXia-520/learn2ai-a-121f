# 第二章综合题：基本不等式与二次不等式

对应资料：`materials/02-讲义/必修一-第2章-一元二次函数、方程和不等式.md`

满分 20 分，建议用时 25 分钟。本题不需要使用导数。

## 题目

设 `F(x) = x + 9/(x - 2)`，其中 `x` 为实数，且 `x != 2`。

**（1）最值与取等条件（5 分）**

当 `x > 2` 时，用基本不等式求 `F(x)` 的最小值，并求取得最小值时 `x` 的值。写明使用基本不等式的前提，并验证等号能够取到。

**（2）二次方程与不等式的联系（5 分）**

当 `x > 2` 时，解不等式 `F(x) <= 12`。将其转化为一元二次不等式，求出对应方程的根，再结合二次函数的开口方向说明解集及端点的取舍。

**（3）含参恒成立与边界（4 分）**

若对任意 `x > 2`，不等式 `F(x) > m` 恒成立，求实数 `m` 的取值范围。若将不等号改为 `F(x) >= m`，取值范围是否改变？分别说明边界值能否取到的理由。

**（4）错解辨析与完整解集（6 分）**

这一问不再限定 `x > 2`，只要求 `x != 2`。某同学解不等式 `F(x) <= 12` 的过程如下：

> 在不等式两边同乘 `x - 2`，得到 `x(x - 2) + 9 <= 12(x - 2)`，即 `x^2 - 14x + 33 <= 0`。
>
> 因式分解得 `(x - 3)(x - 11) <= 0`，所以解集为 `[3, 11]`。

判断这份解答是否正确。若有错误，指出出错的具体步骤，给出一个被漏掉的解作为反例，并按 `x - 2` 的符号分类讨论，求出原不等式的完整解集。
