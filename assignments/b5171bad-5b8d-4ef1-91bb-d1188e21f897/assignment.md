# 第一章 集合与常用逻辑用语 · 概念熟练与思考过程作业

> 对应资料：`materials/02-讲义/必修一-第1章-集合与常用逻辑用语.md`

> 本题重点考查两件事：**知识是否真正掌握**（能不能说清依据），以及**解题是否熟练**（能不能又快又准地写出完整过程）。

3. 第一部分的题目要求"结论 + 一句话依据"，不用写长过程；第二、三部分要求完整过程。

## 二、第一部分 · 概念熟练（每小题 4 分，共 20 分）

**第 1 题** 判断下列关系式是否正确，并各用一句话说明依据。

(1) `1 ∈ {1, 2}`　　(2) `{1} ⊆ {1, 2}`　　(3) `1 ⊆ {1, 2}`  
(4) `∅ ⊆ {1, 2}`　　(5) `∅ ∈ {∅}`　　(6) `{0} = ∅`

**第 2 题** 用列举法表示下列集合。

(1) `A = {x ∈ Z | |x| ≤ 2 且 x ≠ 0}`　　(2) `B = {x | x² − x − 6 = 0}`

**第 3 题** 已知全集 `U = {1, 2, 3, 4, 5, 6}`，`A = {1, 3, 5}`，`B = {2, 3, 5}`，求 `A ∪ B`、`A ∩ B`、`∁U(A ∩ B)`。

**第 4 题** 集合 `M = {a, b, c}` 的子集、真子集、非空真子集各有多少个？

**第 5 题** 写出下列命题的否定，并判断原命题的真假。

(1) `∀x ∈ R，x² ≥ 0`  
(2) `∃x ∈ N，x² = x`  
(3) 至少有一个实数 x，使 `x² + x + 1 = 0`

## 三、第二部分 · 方法运用（每小题 12 分，共 36 分）

**第 6 题** 已知集合 `A = {x | −2 ≤ x ≤ 5}`，`B = {x | m + 1 ≤ x ≤ 2m − 1}`。

(1) 当 `m = 3` 时，求 `A ∩ B`；  
(2) 若 `B ⊆ A`，求实数 m 的取值范围。

**第 7 题** 已知全集 `U = R`，集合 `A = {x | −3 < x ≤ 4}`，`B = {x | x < −1 或 x > 3}`。

(1) 求 `A ∩ B`、`A ∪ B` 与 `∁U(A ∩ B)`；  
(2) 若集合 `C = {x | 2a ≤ x ≤ a + 1}` 且 `C ⊆ (A ∩ B)`，求实数 a 的取值范围。

**第 8 题** 已知命题 p：`x² − 8x − 20 ≤ 0`；命题 q：`1 − m ≤ x ≤ 1 + m`（`m > 0`）。

(1) 若 p 是 q 的充分不必要条件，求 m 的取值范围；  
(2) 若 q 是 p 的充分不必要条件，求 m 的取值范围。

> 提示：这一问的两个小问答案不同，请务必把"谁包含谁"想清楚后再动笔。

## 四、第三部分 · 思考过程（共 44 分）

**第 9 题（20 分）** 已知集合 `A = {x | x² + 4x + a = 0}`。

(1) 若 A 中只有一个元素，求 a 的值及此时的集合 A；  
(2) 若 A 中至多有一个元素，求 a 的取值范围；  
(3) 若 `A ⊆ {0, −4}`，求 a 的值。

> **本题必须写出完整的思考过程**，尤其是第 (3) 问：请写清"你是如何想到要分几种情况讨论的""每一种情况为什么成立或不成立""你怎么确认没有漏掉情况"。

**第 10 题（12 分）** 从讲义第一章的"典型例题"中（不含自测题）任选一道，写成一份"讲给同学听"的讲解稿，包含：

① 这道题实际在考查哪些知识点；  
② 解题的**关键一步**在哪里，为什么这一步最容易出错；  
③ 如果同学在这道题上做错了，你会怎么提醒他（不超过 5 句话）；  
④ 自己编一道**同类型**的变式题，并给出完整解答。

> 要求：第 ④ 问的题目不得照抄讲义、自测题或测评卷中的原题；变式题必须与所选例题考查同一方法。

**第 11 题（12 分）** 下面是一道题和两位同学的解答，请判断谁的解答正确，指出错误解答的错因，并给出正确答案。

**题目**：已知集合 `A = {1, 2, 3}`，`B = {x | x² − 3x + m = 0}`，若 `B ⊆ A`，求实数 m 的值。

**同学甲的解答**：因为 1、2、3 都是 A 中的元素，所以把 1、2、3 依次代入方程，令 `x² − 3x + m = 0` 成立即可：

- 代入 `x = 1`：`1 − 3 + m = 0`，得 `m = 2`；
- 代入 `x = 2`：`4 − 6 + m = 0`，得 `m = 2`；
- 代入 `x = 3`：`9 − 9 + m = 0`，得 `m = 0`。

所以 `m = 2` 或 `m = 0`。

**同学乙的解答**：由 `B ⊆ A`，B 中的元素只能从 1、2、3 中取。又因为方程两根之和为 3，所以分三种情况：

- B 有两个元素：两根只能取 1 和 2，此时 `m = 1 × 2 = 2`，检验得 `B = {1, 2} ⊆ A`，符合；
- B 有一个元素：判别式 `9 − 4m = 0`，得 `m = 9/4`，此时 `B = {3/2}`，而 `3/2 ∉ A`，不符合，舍去；
- B 为空集：判别式 `9 − 4m < 0`，得 `m > 9/4`，此时 `B = ∅ ⊆ A`，符合。

所以 `m = 2` 或 `m > 9/4`。

**请作答**：

(1) 谁的解答正确？  
(2) 另一位同学的错解中，具体是哪一步推理出了问题？请举出反例（把具体的 m 值代入，算出集合 B 与 A 的关系）。  
(3) 写出你认为规范的完整解法。
