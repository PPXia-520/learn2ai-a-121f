# 第 11 题 · 辨析：`B ⊆ A` 不能翻译成「把 A 的元素往方程里代」

## 一、谁的解答正确

**同学乙的解答正确**，答案为 `m = 2` 或 `m > 9/4`。

同学甲的答案（`m = 2` 或 `m = 0`）中，`m = 2` 恰好对，但 `m = 0` 是错的，并且漏掉了 `m > 9/4` 这一整段。

## 二、甲具体是哪一步推理出了问题

甲的推理是：「因为 1、2、3 都是 A 中的元素，所以把 1、2、3 依次代入方程，令它成立即可。」

**错因：他把 `B ⊆ A`（B 中的元素都要在 A 中）反着用成了「A 中的元素都要是方程的根」。**

`B ⊆ A` 只要求「方程的解都在 `{1, 2, 3}` 里」，并不要求 `1`、`2`、`3` 都是方程的解。甲逐个代入，只保证了「1 或 2 或 3 中的某一个可能是根」，却没有检查方程的**另一个根**是否也落在 A 中。

**反例（代入具体 m 值）**：取甲算出的 `m = 0`，方程变为

`x² − 3x + 0 = 0`，即 `x(x − 3) = 0`，解得 `x = 0` 或 `x = 3`，

所以 `B = {0, 3}`。此时 `3 ∈ A`，但 `0 ∉ A = {1, 2, 3}`，因此 `B ⊄ A`，`m = 0` 不成立。

第二个漏洞：甲完全没有考虑 `B = ∅` 的情形。当 `m > 9/4` 时方程无实根，`B = ∅ ⊆ A` 同样成立，而甲漏掉了这一整段。

补充说明：甲代入 `x = 1`、`x = 2` 都得到 `m = 2`，恰好撞上了正确答案，这掩盖了他方法上的问题——`m = 2` 之所以正确，并不是因为「2 是 A 的元素」，而是因为「`m = 2` 时恰好有 `B = {1, 2} ⊆ A`」。

## 三、规范的完整解法

已知 `A = {1, 2, 3}`，`B = {x | x² − 3x + m = 0}`，且 `B ⊆ A`。

`B` 的元素个数由判别式 `Δ = 9 − 4m` 决定，按个数分类讨论：

**(1) `B` 有两个元素**

设两根为 α、β。由韦达定理 `α + β = 3`，且 α ≠ β、α, β ∈ {1, 2, 3}。

从 `{1, 2, 3}` 中取两个不同的数，和为 3 的只有 `1 + 2 = 3`，故 `α, β` 只能是 1 和 2。

由 `αβ = m` 得 `m = 1 × 2 = 2`。

检验：`m = 2` 时 `x² − 3x + 2 = (x − 1)(x − 2) = 0`，`B = {1, 2} ⊆ A` ✓。

**(2) `B` 恰有一个元素**

`Δ = 0`，即 `9 − 4m = 0`，得 `m = 9/4`。

此时重根 `x = 3/2`，`B = {3/2}`，而 `3/2 ∉ A`，不符合 `B ⊆ A`，舍去。

**(3) `B` 为空集**

`Δ < 0`，即 `9 − 4m < 0`，得 `m > 9/4`。

此时 `B = ∅ ⊆ A`，符合。

**综上**：`m = 2` 或 `m > 9/4`。

## 四、检验

- `m = 2`：`B = {1, 2} ⊆ A` ✓
- `m = 3`（属于 `m > 9/4`）：`Δ = 9 − 12 = −3 < 0`，`B = ∅ ⊆ A` ✓
- `m = 9/4`（被舍去的临界值）：`B = {3/2}`，`3/2 ∉ A` ✗
- `m = 0`（甲的错误答案）：`B = {0, 3}`，`0 ∉ A` ✗
- `m = −1`：`x² − 3x − 1 = 0`，两根为 `(3 ± √13)/2`，都不属于 A ✗
