## 第一部分 · 概念熟练

### 第 1 题

**(1) `1 ∈ {1, 2}`：正确。**

- ② 依据：`1` 是集合 `{1, 2}` 中列出的对象，属于该集合。
- ③ 提醒：判断「元素与集合」的关系只能用 `∈` 或 `∉`。

**(2) `{1} ⊆ {1, 2}`：正确。**

- ② 依据：`{1}` 中唯一的元素 `1` 属于 `{1, 2}`，即 `{1}` 的每个元素都是 `{1, 2}` 的元素。
- ③ 提醒：这是「集合与集合」的关系，要用 `⊆`。

**(3) `1 ⊆ {1, 2}`：错误。**

- ② 依据：`1` 是一个数（对象），不是集合，`⊆` 只能连接两个集合；正确写法是 `1 ∈ {1, 2}`。
- ③ 提醒：看等号左边是元素还是集合，决定用 `∈` 还是 `⊆`。

**(4) `∅ ⊆ {1, 2}`：正确。**

- ② 依据：空集不含任何元素，「∅ 中任意元素都属于 `{1, 2}`」是空真命题，所以空集是任何集合的子集。
- ③ 提醒：不能因为 `∅` 里没有元素就把包含关系判错。

**(5) `∅ ∈ {∅}`：正确。**

- ② 依据：`{∅}` 是「以空集为唯一元素」的集合，把 `∅` 当作一个对象代入，确实属于 `{∅}`。
- ③ 提醒：`∅ ∈ {∅}` 对、`∅ ⊆ {∅}` 也对（理由不同）；`∅ ∈ ∅` 才是错的。

**(6) `{0} = ∅`：错误。**

- ② 依据：`{0}` 含 1 个元素 `0`，`∅` 含 0 个元素，元素个数不同，不可能相等。
- ③ 提醒：`0` 是一个数，`{0}` 是「含 0 的集合」，`∅` 是「不含任何元素的集合」，三者互不相同。

### 第 2 题

**(1) `A = {x ∈ Z | |x| ≤ 2 且 x ≠ 0} = {−2, −1, 1, 2}`**

- ② 关键步骤：在整数范围内解 `|x| ≤ 2`，得 `x = −2, −1, 0, 1, 2`；再挖去 `x = 0`，剩 `{−2, −1, 1, 2}`。
- ③ 检验：逐个代入，`|−2| = |2| = 2 ≤ 2`、`|−1| = |1| = 1 ≤ 2`，且都不为 0，符合；四个元素互异。

**(2) `B = {x | x² − x − 6 = 0} = {−2, 3}`**

- ② 关键步骤：因式分解 `x² − x − 6 = (x − 3)(x + 2) = 0`，得 `x = 3` 或 `x = −2`。
- ③ 检验：代回验算，`3² − 3 − 6 = 0`、`(−2)² + 2 − 6 = 0`，均成立。

### 第 3 题

`U = {1, 2, 3, 4, 5, 6}`，`A = {1, 3, 5}`，`B = {2, 3, 5}`。

- ① 结论：`A ∪ B = {1, 2, 3, 5}`；`A ∩ B = {3, 5}`；`∁U(A ∩ B) = {1, 2, 4, 6}`。
- ② 关键步骤：
  - 并集取两者全部元素（`3`、`5` 重复只写一次）：`{1, 2, 3, 5}`；
  - 交集取公共元素（`3`、`5`）：`{3, 5}`；
  - 补集是「在全集 U 中但不在 `A ∩ B` 中」：从 `U` 中挖去 `3`、`5`，得 `{1, 2, 4, 6}`。
- ③ 检验：`(A ∩ B) ∪ ∁U(A ∩ B) = {3, 5} ∪ {1, 2, 4, 6} = U`，且两部分不相交，符合补集定义。
- 提醒：补集依赖全集，本题全集是 `U = {1, 2, 3, 4, 5, 6}` 而不是 `R`。

### 第 4 题

- ① 结论：`M = {a, b, c}` 的子集有 `8` 个，真子集有 `7` 个，非空真子集有 `6` 个。
- ② 关键步骤：`M` 是 3 元集合，子集个数 `2³ = 8`；真子集要去掉 `M` 自己，`8 − 1 = 7`；非空真子集再去掉 `∅`，`8 − 2 = 6`。
- ③ 检验：8 个子集为 `∅、{a}、{b}、{c}、{a,b}、{a,c}、{b,c}、{a,b,c}`；去掉 `{a,b,c}` 得 7 个真子集，再去掉 `∅` 得 6 个非空真子集，与公式一致。

### 第 5 题

**(1) 原命题：`∀x ∈ R, x² ≥ 0`**

- ① 否定：`∃x ∈ R, x² < 0`；原命题为**真**。
- ② 关键步骤：含量词命题的否定「改量词、否结论」——`∀` 改成 `∃`，结论 `x² ≥ 0` 取反为 `x² < 0`。
- ③ 检验：任何实数的平方都非负，找不到满足 `x² < 0` 的实数，故否定为假、原命题为真。

**(2) 原命题：`∃x ∈ N, x² = x`**

- ① 否定：`∀x ∈ N, x² ≠ x`；原命题为**真**。
- ② 关键步骤：`∃` 改成 `∀`，结论取反。举实例：`x = 0` 时 `0² = 0`，`x = 1` 时 `1² = 1`，都在 `N` 中。
- ③ 检验：找到一个例子即可肯定存在量词命题，故原命题真、否定假。

**(3) 原命题：至少有一个实数 x，使 `x² + x + 1 = 0`**

- ① 否定：对任意实数 x，都有 `x² + x + 1 ≠ 0`（即 `∀x ∈ R, x² + x + 1 ≠ 0`）；原命题为**假**。
- ② 关键步骤：先翻译成符号语言 `∃x ∈ R, x² + x + 1 = 0`，再「改量词、否结论」。判断真假用判别式 `Δ = 1² − 4 × 1 × 1 = −3 < 0`，方程无实根。
- ③ 检验：配方得 `x² + x + 1 = (x + 1/2)² + 3/4 ≥ 3/4 > 0`，恒不为 0，说明「一个实数都没有」，原命题为假、否定为真。

## 第二部分 · 方法运用

### 第 6 题

`A = {x | −2 ≤ x ≤ 5}`，`B = {x | m + 1 ≤ x ≤ 2m − 1}`。

**(1) 当 `m = 3` 时**

- ① 结论：`B = {x | 4 ≤ x ≤ 5}`，`A ∩ B = {x | 4 ≤ x ≤ 5}`。
- ② 关键步骤：把 `m = 3` 代入得 `B = {x | 4 ≤ x ≤ 5}`；`A = [−2, 5]`，两集合的公共部分是 `[4, 5]`。
- ③ 检验：画数轴确认公共段；`4`、`5` 同时属于 A、B；取 `x = 3.5` 则 `3.5 ∉ B`，说明交集左端点确实是 4。

**(2) 若 `B ⊆ A`，求 m 的取值范围**

- ① 结论：`m ≤ 3`。
- ② 关键步骤（必须先讨论 `B = ∅`）：
  - **情况一：`B = ∅`。** 此时 `m + 1 > 2m − 1`，解得 `m < 2`。空集是任何集合的子集，故 `B ⊆ A` 成立。
  - **情况二：`B ≠ ∅`。** 此时 `m + 1 ≤ 2m − 1`，即 `m ≥ 2`。要让 `[m + 1, 2m − 1] ⊆ [−2, 5]`，左端点不能小于 `−2`、右端点不能大于 `5`：由 `m + 1 ≥ −2` 得 `m ≥ −3`，由 `2m − 1 ≤ 5` 得 `m ≤ 3`；与 `m ≥ 2` 取交集得 `2 ≤ m ≤ 3`。
  - 两种情况取并集：`m < 2` 或 `2 ≤ m ≤ 3`，即 `m ≤ 3`。
- ③ 检验：`m = 3` 时 `B = [4, 5] ⊆ A` ✓；`m = 2` 时 `B = {3} ⊆ A` ✓；`m = 2.5` 时 `B = [3.5, 4] ⊆ A` ✓；`m = 3.1` 时 `B = [4.1, 5.2]`，`5.2 > 5` ✗；`m = 1` 时 `B = ∅ ⊆ A` ✓。
- 提醒：本题最容易漏掉 `B = ∅`。若只按 `B ≠ ∅` 讨论，会误答成 `2 ≤ m ≤ 3`，丢掉 `m < 2` 这一整段。

### 第 7 题

`U = R`，`A = {x | −3 < x ≤ 4}`，`B = {x | x < −1 或 x > 3}`。

**(1) 求 `A ∩ B`、`A ∪ B`、`∁U(A ∩ B)`**

- ① 结论：
  - `A ∩ B = {x | −3 < x < −1 或 3 < x ≤ 4}`；
  - `A ∪ B = R`；
  - `∁U(A ∩ B) = {x | x ≤ −3 或 −1 ≤ x ≤ 3 或 x > 4}`。
- ② 关键步骤：画数轴。`A = (−3, 4]`，`B = (−∞, −1) ∪ (3, +∞)`。
  - 交集：`A` 与 `B` 的两段分别相交，得 `(−3, −1) ∪ (3, 4]`。
  - 并集：`(−3, 4] ∪ (−∞, −1) = (−∞, 4]`，再并上 `(3, +∞)` 后覆盖整条数轴，得 `R`。
  - 补集：从数轴挖去 `(−3, −1) ∪ (3, 4]`，剩 `(−∞, −3] ∪ [−1, 3] ∪ (4, +∞)`。端点归属要逐个判：`−3`、`−1`、`3` 都不在 `A ∩ B` 中，故补集里取到（实心）；`4 ∈ A ∩ B`，故补集里不取（空心）。
- ③ 检验：取 `x = 0`，`0 ∉ A ∩ B`，而 `−1 ≤ 0 ≤ 3` 故 `0 ∈ ∁U(A ∩ B)` ✓；取 `x = 3`，`3 ∈ B` 但 `3 ∉ A`，所以 `3 ∉ A ∩ B`，而 `3 ∈ ∁U(A ∩ B)` ✓。
- 提醒：`−1`、`3` 在 `A ∩ B` 中取不到（`B` 是开的），在补集中就要取到，实心与空心不能写反。

**(2) 若 `C = {x | 2a ≤ x ≤ a + 1}` 且 `C ⊆ (A ∩ B)`，求 a 的取值范围**

- ① 结论：`a > 1`。
- ② 关键步骤（同样先讨论 `C = ∅`）：
  - **情况一：`C = ∅`。** `2a > a + 1`，解得 `a > 1`。此时 `C ⊆ (A ∩ B)` 自然成立。
  - **情况二：`C ≠ ∅`。** 此时 `a ≤ 1`。`C = [2a, a + 1]` 是一整段连续区间，而 `A ∩ B = (−3, −1) ∪ (3, 4]` 是两段互不相邻的区间，所以 `C` 只能整段落在其中一段里。
    - 若 `C ⊆ (−3, −1)`：需 `2a > −3` 且 `a + 1 < −1`，即 `a > −3/2` 且 `a < −2`，无解。
    - 若 `C ⊆ (3, 4]`：需 `2a > 3` 且 `a + 1 ≤ 4`，即 `a > 3/2` 且 `a ≤ 3`，与 `a ≤ 1` 矛盾，无解。
    - 故情况二无解。
  - 综合得 `a > 1`。
- ③ 检验：`a = 2` 时 `C = [4, 3]`（左端点大于右端点，`C = ∅`）✓；`a = 1.2` 时 `C = [2.4, 2.2] = ∅` ✓；`a = 1` 时 `C = {2}`，`2 ∉ A ∩ B` ✗；`a = 0` 时 `C = [0, 1]`，`0 ∉ A ∩ B` ✗。
- 提醒：这是「空集优先」的典型题——非空情况实际无解，答案几乎全部来自「`C` 是空集」。若一上来就假设 `C` 非空、硬把区间往 `(3, 4]` 里塞，会得到 `a > 3/2` 这种漏掉 `(1, 3/2]` 的错误答案。

### 第 8 题

`p: x² − 8x − 20 ≤ 0`，`q: 1 − m ≤ x ≤ 1 + m`（`m > 0`）。

先把 p 解成区间：`x² − 8x − 20 = (x − 10)(x + 2) ≤ 0`，得 `−2 ≤ x ≤ 10`，即 `P = [−2, 10]`；`Q = [1 − m, 1 + m]`，由 `m > 0` 知 Q 非空。

**(1) 若 p 是 q 的充分不必要条件，求 m 的取值范围**

- ① 结论：`m ≥ 9`。
- ② 关键步骤：p 是 q 的充分不必要条件 ⟺ `P ⊊ Q`（P 是 Q 的真子集，即「P 小、Q 大」）。要 Q 包含 P 且不相等：`1 − m ≤ −2` 且 `1 + m ≥ 10`，即 `m ≥ 3` 且 `m ≥ 9`，取交集得 `m ≥ 9`。此时 Q 的两端都伸到 P 之外，是严格包含。
- ③ 检验：`m = 9` 时 `Q = [−8, 10] ⊋ [−2, 10] = P` ✓；`m = 8` 时 `Q = [−7, 9]`，`10 ∈ P` 但 `10 ∉ Q`，说明 `P ⊄ Q` ✗。

**(2) 若 q 是 p 的充分不必要条件，求 m 的取值范围**

- ① 结论：`0 < m ≤ 3`。
- ② 关键步骤：q 是 p 的充分不必要条件 ⟺ `Q ⊊ P`（「Q 小、P 大」）。要 `[1 − m, 1 + m] ⊆ [−2, 10]` 且不相等：`1 − m ≥ −2` 且 `1 + m ≤ 10`，即 `m ≤ 3` 且 `m ≤ 9`，取交集得 `m ≤ 3`；再结合题设 `m > 0`，得 `0 < m ≤ 3`。此时 Q 长为 `2m < 12 = P 的长`，严格包含成立。
- ③ 检验：`m = 3` 时 `Q = [−2, 4] ⊊ [−2, 10] = P` ✓；`m = 4` 时 `Q = [−3, 5]`，`−3 ∈ Q` 但 `−3 ∉ P`，故 `Q ⊄ P` ✗。
- 提醒：两问方向正好相反——(1) 是「P 小 Q 大」，(2) 是「Q 小 P 大」。先把两个集合都写成区间，再问「谁包含谁」，最后才比较端点；口诀是「小范围推大范围」。

### 第 9 题

`A = {x | x² + 4x + a = 0}`（按题目语境 x 取实数）。

**(1) 若 A 中只有一个元素，求 a 的值及此时的集合 A**

- ① 结论：`a = 4`，`A = {−2}`。
- ② 关键步骤：A 只有一个元素 ⟺ 方程 `x² + 4x + a = 0` 有两个相等实根 ⟺ `Δ = 4² − 4a = 16 − 4a = 0`，解得 `a = 4`。代回得 `x² + 4x + 4 = 0`，即 `(x + 2)² = 0`，`x = −2`。
- ③ 检验：`a = 4` 代回，`(−2)² + 4 × (−2) + 4 = 0` ✓，且是完全平方、只有唯一根，故 `A = {−2}`。
- 提醒：本题二次项系数恒为 1，方程不会退化成一次方程，所以「只有一个元素」只会由 `Δ = 0` 产生。

**(2) 若 A 中至多有一个元素，求 a 的取值范围**

- ① 结论：`a ≥ 4`。
- ② 关键步骤：「至多有一个元素」含两种情形——0 个元素（方程无实根，`Δ < 0`）或 1 个元素（`Δ = 0`）。于是 `Δ = 16 − 4a ≤ 0`，解得 `a ≥ 4`。
- ③ 检验：`a = 4` 时 `A = {−2}`，1 个元素 ✓；`a = 5` 时 `Δ = −4 < 0`，`A = ∅`，0 个元素 ✓；`a = 3` 时 `Δ = 4 > 0`，两根，2 个元素 ✗。
- 提醒：`A = ∅` 也满足「至多一个」，不能把空集这一支漏掉。

**(3) 若 `A ⊆ {0, −4}`，求 a 的值**

- ① 结论：`a = 0` 或 `a > 4`。
- ② 关键步骤：`A ⊆ {0, −4}` 表示「方程的所有实根只能从 `0`、`−4` 中取」。按 A 的元素个数分类讨论（个数由判别式决定，只可能是 0、1、2）：
  - **`A = ∅`（0 个元素）**：`Δ = 16 − 4a < 0`，即 `a > 4`。此时 `∅ ⊆ {0, −4}` 成立。
  - **`A` 恰有 2 个元素**：两根必须正好是 `0` 和 `−4`。由韦达定理，两根之和 `= −4 = 0 + (−4)`（自动满足），两根之积 `= a = 0 × (−4) = 0`，得 `a = 0`。代回：`x² + 4x = 0`，`x(x + 4) = 0`，`A = {0, −4} ⊆ {0, −4}` ✓。
  - **`A` 恰有 1 个元素**：设重根为 `x₀`，两根之和 `2x₀ = −4`，得 `x₀ = −2`，而 `−2 ∉ {0, −4}`，不满足 `A ⊆ {0, −4}`，舍去（等价地：`Δ = 0` 给 `a = 4`，此时 `A = {−2}`）。
  - 综合：`a = 0` 或 `a > 4`。
- ③ 检验（逐一代入）：`a = 0` → `A = {0, −4} ⊆ {0, −4}` ✓；`a = 4` → `A = {−2}` ✗；`a = 5` → `A = ∅` ✓；`a = −5` → `x² + 4x − 5 = 0`，`A = {−5, 1}` ✗；`a = 3` → `Δ = 4 > 0`，`A = {−1, −3}` ✗。
- 思考过程说明（怎么想到分情况、怎么确认不漏）：我抓住的是「A 的元素个数只能由判别式决定，非 0 即 1 即 2」这条线。先分 0 个元素（`A = ∅`，只要 `a > 4` 就一定含于任何集合，包括 `{0, −4}`）；再分 2 个元素（两根之和被固定为 `−4`，从 `{0, −4}` 里能凑出和 `−4` 的只有 `{0, −4}` 本身，用两根之积立刻定出 `a = 0`）；最后分 1 个元素（重根必须是 `−2`，被「根要在 `{0, −4}` 中」否掉）。三种个数都查过、每种都做了代回检验，所以没有漏情况。
