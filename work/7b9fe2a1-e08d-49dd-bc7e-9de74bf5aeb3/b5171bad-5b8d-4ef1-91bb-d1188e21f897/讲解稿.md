# 第 10 题 · 讲解稿：把「充分不必要」翻译成集合的包含关系

> 选题说明：选自讲义「三、典型例题」中的**例 6**（不是自测题）。

## 一、原题

已知 `p: −2 ≤ x ≤ 10`，`q: 1 − m ≤ x ≤ 1 + m (m > 0)`。若 p 是 q 的充分不必要条件，求 m 的取值范围。

## 二、这道题实际在考查哪些知识点

1. **充分条件、必要条件、充要条件的定义**：由 `p ⟹ q` 判断「谁充分、谁必要」。
2. **用集合的包含关系刻画逻辑关系**：记 `P = {x | p(x)}`、`Q = {x | q(x)}`，则 `p ⟹ q` ⟺ `P ⊆ Q`；p 是 q 的充分不必要条件 ⟺ `P ⊊ Q`（真子集）。
3. **区间端点的比较与临界值验证**：把包含关系换成两组端点不等式，并检验端点能否取到。
4. **分类意识**：题设 `m > 0` 保证了 `Q` 非空；要知道这一类「集合是否为空」的前置讨论是被题设省掉的，换个题就可能要自己补上。

## 三、解题的关键一步，以及为什么这一步最容易出错

**关键一步：把「p 是 q 的充分不必要条件」翻译成 `P ⊊ Q`。**

理由：p 是 q 的充分条件 ⟺ 满足 p 的对象一定满足 q ⟺ `P ⊆ Q`；「不必要」意味着反推不成立，即存在满足 q 但不满足 p 的对象，所以 `Q` 中有元素不在 `P` 里，于是 `P ⊊ Q`（真包含）。

写出 `P = [−2, 10]`、`Q = [1 − m, 1 + m]` 后，`P ⊊ Q` 就变成「Q 的两端都要伸到 P 之外」：

`1 − m ≤ −2` 且 `1 + m ≥ 10` ⟹ `m ≥ 3` 且 `m ≥ 9` ⟹ `m ≥ 9`。

**最容易错的地方：**

- **只卡一侧端点。** 很多同学只看到左端 `1 − m ≤ −2`，得到 `m ≥ 3` 就停了，忘了右端 `10 ≤ 1 + m` 还需要 `m ≥ 9`。区间包含必须「两头都盖住」。
- **把方向记反。** 把「p 是 q 的充分不必要条件」错写成 `P ⊋ Q`，于是去解 `m ≤ 3`，方向整个反掉。口诀是「**小范围推大范围**」：`P` 能推出 `Q`，说明 `P` 是较小的那个。
- **取交集写成取并集。** `m ≥ 3` 与 `m ≥ 9` 要取交集得 `m ≥ 9`，不能写成并集。
- **忘记验证严格性。** `m = 9` 时 `Q = [−8, 10]`，`−8 < −2` 说明 `Q` 确实比 `P` 真大，包含是严格的，答案要含 `m = 9`。

## 四、如果同学在这道题上做错了，我会这样提醒他

1. 先把 p、q 各自解成区间，写成 `P`、`Q`，不要停在文字上。
2. 把「充分不必要」翻译成 `P ⊊ Q`——记住「小范围推大范围」，推出别人的那个才是小的。
3. 区间真包含要**两端**都比对方宽，两个端点不等式缺一不可。
4. 算完把临界值代回去，确认包含是「真」的，而不是取了等号。
5. 如果答案只用了一侧条件，就回头检查是不是漏了另一个端点。

## 五、自编变式题（同类型：由充分不必要条件求参数）及解答

**变式题**：已知 `p: 1 ≤ x ≤ 3`，`q: m − 1 ≤ x ≤ m + 4`。若 p 是 q 的充分不必要条件，求实数 m 的取值范围。

**解答**：

记 `P = {x | 1 ≤ x ≤ 3} = [1, 3]`，`Q = {x | m − 1 ≤ x ≤ m + 4} = [m − 1, m + 4]`。

p 是 q 的充分不必要条件 ⟺ `P ⊊ Q`，即 `Q` 要把 `P` 完整盖住，并且比 `P` 大。

- 左端：`m − 1 ≤ 1`，即 `m ≤ 2`；
- 右端：`m + 4 ≥ 3`，即 `m ≥ −1`。

所以 `−1 ≤ m ≤ 2`。

**严格性检验**：当 `−1 ≤ m ≤ 2` 时，`Q` 的区间长度为 `(m + 4) − (m − 1) = 5`，而 `P` 的长度为 `3 − 1 = 2`，且 `P ⊆ Q`，故 `P ⊊ Q` 成立（是真包含，不是相等）。

**端点代回验证**：

- `m = 2`：`Q = [1, 6] ⊋ [1, 3] = P` ✓；
- `m = −1`：`Q = [−2, 3] ⊋ [1, 3] = P` ✓；
- `m = 2.1`：`Q = [1.1, 6.1]`，`1 ∈ P` 但 `1 ∉ Q`，`P ⊄ Q` ✗。

**答**：`−1 ≤ m ≤ 2`。

> 变式说明：与原题考查同一方法（「充分不必要 ⟺ 真子集」＋两端点比较），但把结论从原题的单侧区间 `m ≥ 9` 换成了闭区间 `−1 ≤ m ≤ 2`，并且用「区间长度对比」来验证严格性，避免照抄原题。
